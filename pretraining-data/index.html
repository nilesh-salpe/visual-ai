📚 Reading list🔤 Glossary
01

Where pretraining data comes from

Common Crawl, WARC (Web ARChive format)/WET (plain text extracted from Web ARChive records), and the ~90% a pipeline removes.

02

How a web crawler works

Frontier, per-host politeness, robots checks, normalisation.

03

Crawling at scale

IRLbot's 6.3B pages, budgets, traps, simhash, freshness.

04

robots.txt and consent

RFC 9309 rules and the rise of AI (artificial intelligence) opt-outs.

05

Text extraction

Boilerplate removal, link density, trafilatura, language ID (identifier).

06

Quality filtering

C4 and Gopher rules, CCNet perplexity, DCLM (DataComp for Language Models) and FineWeb-Edu classifiers.

07

Deduplication

Exact hashes, MinHash + LSH, line and substring dedup.

08

PII and safety filtering

Domain blocklists, regex masking, toxicity classifiers.

09

Data mixtures and repetition

Temperature sampling, DoReMi, the ~4-epoch rule.

10

Reference pipelines

C4 → Gopher → RefinedWeb → FineWeb → DCLM → Dolma → Llama 3.
