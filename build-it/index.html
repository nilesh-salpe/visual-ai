Hands-on · Google Colab

Build it

Implement the systems behind the decks yourself. Each notebook runs in Google Colab with NumPy on CPU (central processing unit), so no GPU (graphics processing unit) or setup is needed.

How each notebook works

  1. Click Open in Colab, then run the Setup cell.
  2. Fill in each TODO, then run the collapsed Tests cell under it: ⏳ not done · ✅ passed · ❌ failed, with the reason.
  3. Stuck? Reference solutions are collapsed at the bottom. Try first.
  4. The Experiments section uses the solutions to show the effect at scale.
