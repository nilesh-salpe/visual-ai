Images as tokens in practice

What multimodal input costs and how it fails: visual-token counts and resolution limits in a production API (application programming interface), many-image requests, audio as another input, benchmarks such as MMMU (Massive Multi-discipline Multimodal Understanding), and object hallucination.

What is the problem?Images make prompts expensive and slow in ways that are easy to miss: a single screenshot can cost thousands of tokens, and agents resend every image on every turn. Models also describe things that are not in the image.
Core ideaEstimate the visual-token cost of every image: the Claude API counts one token per 28 × 28-pixel patch and downsizes images above a tier limit (1,568 px and 1,568 tokens standard; 2,576 px and 4,784 tokens on high-resolution models). Resize before sending, put images before text, and reference repeated images by file. Evaluate on expert multimodal benchmarks (MMMU) and test for object hallucination (POPE (Polling-based Object Probing Evaluation)).

4 · Core idea

Budget, resize, order, evaluate

Count tokens

Claude: ⌈w / 28⌉ × ⌈h / 28⌉ visual tokens; images above the tier limit (standard 1,568 px / 1,568 tokens, high-resolution 2,576 px / 4,784 tokens) are downscaled keeping aspect ratio.

Send them well

Images before text; Files API for repeated images; up to 600 images per request (100 on 200k-context models), with stricter size limits above 20.

Other modalities

Audio is converted to model inputs the same way; Whisper was trained on 680,000 hours of multilingual, multitask audio and transfers zero-shot.

Evaluate hard cases

MMMU: 11.5K college-level questions across 30 subjects and 30 image types; GPT-4V 56%, Gemini Ultra 59%. POPE probes object hallucination with yes/no polling.

5 · How it works

Worked example: a screenshot-heavy agent

A computer-use agent sends a 1920 × 1080 screenshot every step for 30 steps.

Worked example

  1. Standard tier: the screenshot is downsized to 1456 × 819, which costs ⌈1456/28⌉ × ⌈819/28⌉ = 52 × 30 = 1,560 tokens.
  2. High-resolution tier: no downsizing, ⌈1920/28⌉ × ⌈1080/28⌉ = 69 × 39 = 2,691 tokens.
  3. If every past screenshot stays in the context, step 30 carries 30 × 2,691 ≈ 80,700 tokens of images.
  4. Downsample when the extra detail is not needed, drop or summarise old screenshots, and cache stable prefixes.
Image tokens accumulate in agent loops exactly like tool outputs do.
6 · Why it works

Why these limits and failures exist

Attention cost

Every visual token is attended to like text, so resolution is capped to bound compute.

Detail vs budget

High-resolution tiers use up to about three times more tokens; worth it for screenshots and dense documents.

Language priors

Hallucinated objects tend to be ones that occur often in training instructions or co-occur with real objects.

Benchmarks shape progress

Expert-level, diverse image types (charts, maps, chemical structures) expose gaps that captioning hides.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Image cost depends on file size."

It depends on pixel dimensions after resizing, not on bytes or format.

"Sending a higher resolution is always better."

Above the tier limit the image is downsized anyway; below it, more pixels cost more tokens for detail you may not need.

"If the model names an object, it is in the image."

POPE showed severe object hallucination across vision-language models.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Tokens ≈ pixels / 784. One visual token per 28 × 28 patch (Claude API).
  • Images first. Claude works best when images come before the text that refers to them.
  • Upload once. The Files API avoids resending base64 bytes on every turn.

⚠ Traps

  • Many-image requests. Above 20 images per request a stricter per-image size limit applies; keep each side ≤ 2,000 px.
  • Tiny or rotated images. Accuracy drops on low-quality images or ones under 200 pixels.
  • Trusting object lists. Models often mention objects that frequently co-occur with what is in the image, even when absent.

9 · Key takeaway

Key takeaway

Treat images like long text: estimate their tokens, resize them, and check that the model is not seeing things.
