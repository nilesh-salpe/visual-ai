Agent frameworks: key papers

Every paper cited on the decks' Key papers slides, in the order the guide introduces them. Each entry links to the paper and to the decks that use it.

Building effective agents
Anthropic · Anthropic Engineering 2024 · cited in LangChain basics

Workflows (predefined code paths) vs agents (LLMs (large language models) directing their own process); patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer. Start with the simplest solution.

Agents (LangChain)
LangChain documentation · docs.langchain.com 2026 · cited in LangChain basics

create_agent: a model calling tools in a loop until the task is complete; models as "provider:model" strings or objects, tools as callables or LangChain tools, system_prompt, response_format, middleware, and memory via a checkpointer and thread_id.

Tools (LangChain)
LangChain documentation · docs.langchain.com 2026 · cited in LangChain basics

The @tool decorator turns a function into a tool whose name, description (docstring) and argument schema (type hints) are sent to the model.

Middleware (LangChain)
LangChain documentation · docs.langchain.com 2026 · cited in LangChain basics, LangGraph in production

Hooks around the agent loop (before/after agent and model calls, wrappers around model and tool calls) and prebuilt middleware such as summarization, human-in-the-loop approval, call limits, retries, model fallback and PII (personally identifiable information) handling.

OpenAI Agents SDK
OpenAI documentation · openai.github.io 2026 · cited in LangChain basics

Primitives: agents (LLMs with instructions and tools), handoffs and agents-as-tools for delegation, guardrails for input and output validation; plus sessions and built-in tracing.

Agent SDK overview
Anthropic documentation · code.claude.com 2026 · cited in LangChain basics

Claude Code as a library: the same tools, agent loop and context management, with hooks, subagents, MCP (Model Context Protocol), permissions and sessions, in Python and TypeScript.

langchain 1.4.6 and langgraph 1.2.15 (release pins)
PyPI · pypi.org 2026 · cited in LangChain basics

The versions these decks and notebooks are verified against: langchain 1.4.6, langchain-core 1.6.10, langgraph 1.2.15, langgraph-checkpoint 4.3.0.

LangChain v1 migration guide
LangChain documentation · docs.langchain.com 2025 · cited in LangChain basics

Agents are now built with langchain.agents.create_agent (previously langgraph.prebuilt.create_react_agent, deprecated since LangGraph 1.0); legacy chains, retrievers, the indexing API and hub moved to the langchain-classic package.

Graph API (LangGraph)
LangChain documentation · docs.langchain.com 2026 · cited in LangGraph core

State schemas and reducers (the default overwrites), MessagesState and add_messages, nodes, edges and conditional edges, Send and Command; execution in Pregel-style super-steps that ends when all nodes are inactive.

LangGraph overview
LangChain documentation · docs.langchain.com 2026 · cited in LangGraph core

A low-level orchestration runtime for long-running, stateful agents, with durable execution, human-in-the-loop, memory and streaming.

Pregel: A System for Large-Scale Graph Processing
Malewicz et al. · SIGMOD 2010 · cited in LangGraph core

Vertex-centric computation in synchronous super-steps of message passing; the computation halts when every vertex has voted to halt and no messages are in transit. LangGraph's runtime is modelled on it.

ReAct: Synergizing Reasoning and Acting in Language Models
Yao et al. · ICLR 2023 · cited in LangGraph core

Interleaves reasoning traces with actions and observations, so reasoning guides tool use and observations ground reasoning.

Persistence (LangGraph)
LangChain documentation · docs.langchain.com 2026 · cited in LangGraph in production

Checkpointers save thread-scoped graph state for conversation continuity, human-in-the-loop, time travel and fault tolerance; stores keep application data across threads.

Interrupts (LangGraph)
LangChain documentation · docs.langchain.com 2026 · cited in LangGraph in production

interrupt() pauses a run (needs a checkpointer and thread_id); Command(resume=value) continues and the node restarts from the beginning, so code before the interrupt re-runs; no bare try/except around it; keep interrupt order stable.

Streaming (LangGraph)
LangChain documentation · docs.langchain.com 2026 · cited in LangGraph in production

Stream modes for progress and output: values, updates, messages (tokens), custom, checkpoints, tasks and debug.
