The Modern LLM Architecture

What changed after the 2017 Transformer, and why: pre-norm and RMSNorm (root-mean-square normalization), RoPE (rotary position embedding), SwiGLU (Swish-gated linear unit), MQA (multi-query attention)/GQA (grouped-query attention)/MLA (multi-head latent attention), decoder-only stacks, long-context methods, FlashAttention and Mixture of Experts. Every deck follows the 9-beat template, numbers are checked against the source papers and model configs, and each concept has a hands-on Colab notebook. Start with the Attention Is All You Need guide if the 2017 block is new to you.

🛠 Build it: 10 Colab notebooks

Implement RMSNorm, RoPE, SwiGLU, MLA weight absorption, attention masks, PI (Position Interpolation)/NTK (neural tangent kernel)/YaRN (Yet another rotary-position-embedding extension method), a rolling KV (key-value) cache, FlashAttention, an MoE router and a full Llama block in NumPy. Built-in tests, hidden solutions, no GPU (graphics processing unit) needed.
