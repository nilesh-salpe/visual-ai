ReAct: reasoning and acting

The pattern behind most agents: interleave a reasoning step, an action and an observation, and optionally reflect on failures (Reflexion).

What is the problem?Chain-of-thought alone reasons from memory and can hallucinate facts; acting alone (just calling tools) lacks a plan to decide what to do next or how to handle surprises.
Core ideaReAct interleaves Thought → Action → Observation: reasoning decides the next action and interprets results; actions gather facts that ground the reasoning. Reflexion adds a memory of verbal self-critiques from failed attempts that guides the next attempt.

1 · Problem

Reasoning or acting alone

Reason only

Chain-of-thought answers from parametric memory: confident hallucinations, errors propagate.

Act only

Tool calls without a plan wander and cannot recover from unexpected results.

No learning across attempts

A failed attempt teaches nothing to the next one.

2 · Core idea

Interleave thought, action, observation

Thought

Free-text reasoning: what is known, what is missing, what to try next.

Action

A tool call (search, lookup, click, run code).

Observation

The tool's result, appended to the trajectory.

Results (Yao et al., 2023): on HotpotQA and FEVER, ReAct with a simple Wikipedia API (application programming interface) reduced the hallucination and error propagation of chain-of-thought; on ALFWorld and WebShop it beat imitation and reinforcement learning methods by 34 and 10 points absolute success, with one or two in-context examples.

4 · Low-level design

What a trajectory looks like

Question: Which year was the director of "Inception" born?
Thought 1: I need the director of Inception, then their birth year.
Action 1: search["Inception film director"]
Observation 1: Inception (2010) was written and directed by Christopher Nolan.
Thought 2: Now find Christopher Nolan's birth year.
Action 2: search["Christopher Nolan born"]
Observation 2: Christopher Nolan (born 30 July 1970) ...
Thought 3: The answer is 1970.
Action 3: finish["1970"]

Scratchpad

The full trajectory is the context for the next step, so it grows every iteration.

Structured actions

Modern APIs carry actions as tool calls; thoughts may be model reasoning or plain text.

Stop rules

A finish action, a step limit, or repeated identical actions end the loop.

7 · Challenges in production

In production

Traces

Store full thought/action/observation trajectories for debugging and evaluation.

Step budgets

Cap iterations and tokens per task; surface "gave up" honestly.

Success signals

Reflection needs tests or checks you can trust.

Latency

Each thought adds tokens; use the smallest reasoning effort that works.

Further reading

Key papers

The primary sources behind this deck, each with what it contributed. Links go to the paper (arXiv or the conference page).

ReAct: Synergizing Reasoning and Acting in Language Models
Yao et al. · ICLR 2023

Interleaves reasoning traces with actions and observations, so reasoning guides tool use and observations ground reasoning.

Remember: +34 and +10 points absolute success on ALFWorld and WebShop
Reflexion: Language Agents with Verbal Reinforcement Learning
Shinn et al. · NeurIPS 2023

Agents write verbal reflections on failed attempts into an episodic memory and use them on the next trial, without weight updates.

Remember: 91% pass@1 on HumanEval vs 80% for GPT-4
AgentBench: Evaluating LLMs (large language models) as Agents
Liu et al. · ICLR 2024

Eight interactive environments for LLM agents; poor long-term reasoning, decision-making and instruction following are the main failure causes.
