Planning and task decomposition

How agents handle long tasks: plan first and execute, decompose into subtasks with dependencies, search over alternatives, and replan when reality differs from the plan.

What is the problem?Step-by-step greedy decisions drift on long tasks: the agent forgets the goal, repeats work, or commits early to a dead end it cannot back out of.
Core ideaMake the plan explicit. Plan-and-execute: produce a list (or DAG (directed acyclic graph)) of subtasks, then run them. Search: explore alternative partial solutions and evaluate them (Tree of Thoughts). Replan when results contradict the plan. For work you cannot predict, an orchestrator breaks the task down dynamically and delegates.

1 · Problem

Greedy steps drift

Lost goal

After dozens of steps the original objective is buried in context.

Dead ends

An early wrong choice cannot be undone without backtracking.

Missing steps

Zero-shot chain-of-thought skips steps (a failure Plan-and-Solve targets).

2 · Core idea

Make the plan explicit

Plan-and-solve

First devise a plan dividing the task into subtasks, then carry them out (Wang et al., 2023).

Decompose into a DAG

Subtasks with dependencies; independent ones can run in parallel (HuggingGPT plans subtasks and picks a model for each).

Search

Tree of Thoughts explores several reasoning paths with self-evaluation and backtracking: Game of 24 solved 74% vs 4% with chain-of-thought (GPT-4).

Replan

Treat the plan as a hypothesis: revise it when observations disagree.

7 · Challenges in production

In production

Show the plan

Users can approve or edit a plan before expensive or risky execution.

Checkpoint state

Long tasks survive restarts if plan status and results are persisted.

Budget search

Cap branches and depth; search multiplies cost.

Measure

Track plan quality: completed steps, replans, wasted work.

Further reading

Key papers

The primary sources behind this deck, each with what it contributed. Links go to the paper (arXiv or the conference page).

Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models
Wang et al. · ACL 2023

First devise a plan that splits the task into subtasks, then carry them out; reduces missing-step errors of zero-shot chain-of-thought.

Tree of Thoughts: Deliberate Problem Solving with Large Language Models
Yao et al. · NeurIPS 2023

Search over intermediate "thoughts" with self-evaluation, lookahead and backtracking instead of a single left-to-right chain.

Remember: Game of 24: 74% vs 4% with chain-of-thought (GPT-4)
HuggingGPT: Solving AI (artificial intelligence) Tasks with ChatGPT and its Friends in Hugging Face
Shen et al. · NeurIPS 2023

An LLM (large language model) controller plans subtasks, selects specialist models by their descriptions, executes them and summarises the results.

Building effective agents
Anthropic · Anthropic Engineering 2024

Workflows (predefined code paths) vs agents (LLMs directing their own process); patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer. Start with the simplest solution.
