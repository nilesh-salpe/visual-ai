Agent foundations: key papers

Every paper cited on the decks' Key papers slides, in the order the guide introduces them. Each entry links to the paper and to the decks that use it.

Building effective agents
Anthropic · Anthropic Engineering 2024 · cited in What an agent is, Planning and task decomposition

Workflows (predefined code paths) vs agents (LLMs directing their own process); patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer. Start with the simplest solution.

ReAct: Synergizing Reasoning and Acting in Language Models
Yao et al. · ICLR 2023 · cited in What an agent is, ReAct: reasoning and acting

Interleaves reasoning traces with actions and observations, so reasoning guides tool use and observations ground reasoning.

Remember: +34 and +10 points absolute success on ALFWorld and WebShop
Toolformer: Language Models Can Teach Themselves to Use Tools
Schick et al. · NeurIPS 2023 · cited in What an agent is, Tool calling

A model trained self-supervised to decide which APIs to call, when, and with what arguments (calculator, search, QA, translation, calendar).

Tool use with Claude (overview)
Anthropic documentation · platform.claude.com 2026 · cited in Tool calling

Tools defined with input_schema; client tools return stop_reason "tool_use" and are executed by the application, which replies with tool_result; server tools run on Anthropic's side.

Function calling
OpenAI documentation · developers.openai.com 2026 · cited in Tool calling

Function tools defined by JSON Schema with optional strict mode, tool_choice (auto, required, forced) and parallel_tool_calls; results returned as function_call_output items.

Reflexion: Language Agents with Verbal Reinforcement Learning
Shinn et al. · NeurIPS 2023 · cited in ReAct: reasoning and acting

Agents write verbal reflections on failed attempts into an episodic memory and use them on the next trial, without weight updates.

Remember: 91% pass@1 on HumanEval vs 80% for GPT-4
AgentBench: Evaluating LLMs (large language models) as Agents
Liu et al. · ICLR 2024 · cited in ReAct: reasoning and acting

Eight interactive environments for LLM agents; poor long-term reasoning, decision-making and instruction following are the main failure causes.

Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models
Wang et al. · ACL 2023 · cited in Planning and task decomposition

First devise a plan that splits the task into subtasks, then carry them out; reduces missing-step errors of zero-shot chain-of-thought.

Tree of Thoughts: Deliberate Problem Solving with Large Language Models
Yao et al. · NeurIPS 2023 · cited in Planning and task decomposition

Search over intermediate "thoughts" with self-evaluation, lookahead and backtracking instead of a single left-to-right chain.

Remember: Game of 24: 74% vs 4% with chain-of-thought (GPT-4)
HuggingGPT: Solving AI (artificial intelligence) Tasks with ChatGPT and its Friends in Hugging Face
Shen et al. · NeurIPS 2023 · cited in Planning and task decomposition

An LLM (large language model) controller plans subtasks, selects specialist models by their descriptions, executes them and summarises the results.
