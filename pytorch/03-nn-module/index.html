nn.Module and a transformer block

How PyTorch models are built: nn.Module, parameters and buffers, state_dict, and a complete pre-norm transformer block with fused attention (scaled_dot_product_attention).

What is the problem?An LLM (large language model) has dozens of blocks with hundreds of tensors. Code must organise them, count them, move them between devices, save and load them, and run attention efficiently.
Core ideaSubclass nn.Module: assign layers in __init__, compute in forward. Assigned parameters and sub-modules are tracked automatically; buffers (register_buffer) hold non-trainable state. Attention is one call: F.scaled_dot_product_attention(q, k, v, is_causal=True), which picks a fused kernel when available.

2 · Limitation

Why not just write functions?

Bookkeeping

Hundreds of weight tensors must be found for the optimizer, moved to GPUs (graphics processing units), saved and loaded.

Modes

Dropout and normalisation behave differently in training and evaluation.

Attention speed

A hand-written masked softmax materialises the T × T matrix; fused kernels do not.

4 · Core idea

Modules, parameters, buffers

nn.Module

init assigns sub-modules and nn.Parameters; forward computes. Calling the module runs forward plus hooks.

Containers

nn.Sequential, nn.ModuleList, nn.ModuleDict register children so they are tracked.

Buffers

register_buffer for non-trainable tensors (masks, RoPE (rotary position embedding) frequencies); persistent=False keeps them out of state_dict.

state_dict

Name → tensor mapping of parameters and persistent buffers; what checkpoints store.

At a glance

≈ 12C² weights per block (+ 2C norm gains).

5 · How it works

The block in code

class Block(nn.Module):
    def __init__(self, C, H):
        super().__init__()
        self.n1, self.attn = nn.RMSNorm(C), CausalSelfAttention(C, H)
        self.n2 = nn.RMSNorm(C)
        self.mlp = nn.Sequential(nn.Linear(C, 4*C, bias=False), nn.GELU(),
                                 nn.Linear(4*C, C, bias=False))
    def forward(self, x):
        x = x + self.attn(self.n1(x))
        return x + self.mlp(self.n2(x))

# inside CausalSelfAttention.forward:
y = F.scaled_dot_product_attention(q, k, v, is_causal=True)   # (B, H, T, D)

SDPA backends

scaled_dot_product_attention dispatches to one of FLASH_ATTENTION, EFFICIENT_ATTENTION, CUDNN_ATTENTION or MATH (the SDPBackend enum), depending on hardware, dtype and inputs. torch.nn.attention.sdpa_kernel restricts the choice. It also accepts enable_gqa=True for grouped-query attention.

5 · How it works

Worked example: counting GPT-2 small's parameters

GPT-2 small (as in nanoGPT): C = 768, 12 layers, vocabulary 50,257, context 1,024, tied embeddings. Each block ≈ 12C² weights.

Worked example

  1. Per block: 12 × 768² = 7.08M; × 12 blocks = 84.9M.
  2. Token embedding: 50,257 × 768 = 38.6M (reused as the output head); positions 1,024 × 768 = 0.79M.
  3. Total ≈ 124M, plus biases and LayerNorm parameters: nanoGPT reports 124M.
  4. Notebook 03 checks the formula exactly for its RMSNorm (root-mean-square normalization) block without biases: 12 × 64² + 2 × 64 = 49,280.
Shapes give parameter counts directly; tying the head to the embedding saves a whole V × C matrix.
6 · Why it works

Why this structure works

Automatic tracking

Assigning attributes registers parameters, so optimizers, .to(), FSDP (Fully Sharded Data Parallel) and checkpoints find them.

Composable

A model is a tree of modules; blocks are reused, replaced (LoRA (Low-Rank Adaptation)) or wrapped (FSDP) per sub-module.

Fused attention for free

One SDPA (scaled dot-product attention) call gets FlashAttention-class kernels on supported GPUs.

Testable

Each module can be checked alone against a reference, as notebook 03 does.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Buffers are trained like parameters."

Buffers are never returned by parameters(), so optimizers never update them.

"SDPA is an approximation."

It computes exact attention; fused backends just avoid storing the score matrix.

"state_dict contains the optimizer state."

Only the model's parameters and persistent buffers; the optimizer has its own state_dict.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • sum(p.numel() for p in m.parameters()). The parameter count.
  • register_buffer(…, persistent=False). For caches that should not be saved (e.g. RoPE tables you can recompute).
  • is_causal=True. Instead of building a T×T mask.

⚠ Traps

  • Plain Python lists of layers. Use nn.ModuleList, or parameters are not registered.
  • Building a mask and passing is_causal too. Use one or the other.
  • Forgetting model.eval(). Dropout stays active during evaluation.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

Parameters in one block with C = 1,024 (12C² + 2C)?

12 × 1,024² + 2,048 ≈ 12.6M.

When would you use register_buffer(…, persistent=False)?

For derived, non-trainable state you can recompute (causal masks, RoPE caches) that should not be saved in checkpoints.

What does is_causal=True do in SDPA?

Applies a lower-triangular causal mask so each position attends only to itself and earlier positions, without building the mask tensor.
9 · Key takeaway

Key takeaway

Models are trees of nn.Modules whose parameters and buffers are tracked automatically; a pre-norm block is two residual branches around SDPA attention and an MLP (multilayer perceptron), ≈ 12C² weights.
Say it in 30 seconds

In PyTorch a model is an nn.Module: you assign layers in init and compute in forward, and every parameter you assign is tracked, so optimizers, device moves, sharding and checkpoints find it. Containers like ModuleList register children; buffers hold non-trainable state such as masks or rotary tables. A pre-norm transformer block is x plus attention of the normalised x, then x plus an MLP of the normalised x. Attention is one call to scaled dot product attention with is_causal set, which uses fused kernels such as FlashAttention when the hardware allows.
