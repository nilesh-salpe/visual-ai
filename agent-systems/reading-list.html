Agent systems: key papers

Every paper cited on the decks' Key papers slides, in the order the guide introduces them. Each entry links to the paper and to the decks that use it.

How we built our multi-agent research system
Anthropic · Anthropic Engineering 2025 · cited in Multi-agent systems

A lead agent plans and spawns parallel subagents with separate context windows; lessons on delegation, effort scaling, tools, evaluation and production reliability.

Remember: +90.2% vs single agent on an internal research eval; ~15× chat tokens
AutoGen: Enabling Next-Gen LLM (large language model) Applications via Multi-Agent Conversation
Wu et al. · COLM 2024 · cited in Multi-agent systems

A framework of conversable agents (LLMs, humans, tools) whose interaction patterns are programmed in natural language and code.

Building effective agents
Anthropic · Anthropic Engineering 2024 · cited in Multi-agent systems

Workflows (predefined code paths) vs agents (LLMs directing their own process); patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer. Start with the simplest solution.

Computer use tool
Anthropic documentation · platform.claude.com 2026 · cited in Computer and browser use

Screenshot, mouse and keyboard control in an agent loop; recommends a dedicated VM or container, no sensitive data, a domain allowlist and human confirmation for consequential actions.

OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments
Xie et al. · NeurIPS 2024 · cited in Computer and browser use

369 real desktop and web tasks across operating systems with execution-based evaluation scripts.

Remember: humans 72.36% vs best model 12.24% (at release)
WebArena: A Realistic Web Environment for Building Autonomous Agents
Zhou et al. · ICLR 2024 · cited in Computer and browser use

Self-hosted, functional websites (shopping, forums, code hosting, CMS (content management system)) with tasks graded on functional correctness.

Remember: best GPT-4 agent 14.41% vs humans 78.24% (at release)
Temporal Workflows
Temporal documentation · docs.temporal.io 2026 · cited in Durable workflows for agents

Workflow code is replayed against the recorded event history to rebuild state (no memory snapshots), so it must be deterministic; activities do the side effects and their results are recorded once and reused on replay.

Retry policies (Temporal)
Temporal documentation · docs.temporal.io 2026 · cited in Durable workflows for agents

Activity defaults: initial interval 1 s, backoff 2.0, maximum interval 100 × initial, unlimited attempts; workflows do not retry by default.

Temporal Workflow Execution limits
Temporal documentation · docs.temporal.io 2026 · cited in Durable workflows for agents

Event History is limited to 51,200 events or 50 MB, with warnings after 10,240 events or 10 MB.

Persistence (LangGraph)
LangChain documentation · docs.langchain.com 2026 · cited in Durable workflows for agents

Checkpointers save thread-scoped graph state for conversation continuity, human-in-the-loop, time travel and fault tolerance; stores keep application data across threads.

Apache Airflow documentation (3.x)
Apache Software Foundation · airflow.apache.org 2026 · cited in Durable workflows for agents

A platform for developing, scheduling and monitoring workflows defined as Python DAGs; aimed at batch workflows with a clear start and end.

Argo Workflows documentation
Argo Project (CNCF) · argo-workflows.readthedocs.io 2026 · cited in Durable workflows for agents

A container-native workflow engine for Kubernetes implemented as a CRD; each step runs as a container, as steps or a DAG; used for machine-learning pipelines, batch processing, and continuous integration and delivery.
