Attention Is All You Need · 02

The Transformer architecture

An encoder-decoder built entirely from attention and position-wise feed-forward layers, with no recurrence and no convolution.

What is the problem?Earlier sequence models relied on recurrence or convolution, so the number of operations needed to relate two positions grew with the distance between them.
Core ideaStack N = 6 identical encoder layers and N = 6 decoder layers built from multi-head attention and feed-forward sub-layers, each wrapped in a residual connection and layer normalization.
1 · Problem

Sequence transduction: read one sequence, write another

Machine translation maps an input sequence (English) to an output sequence (German) of a different length and word order. The standard design in 2017 was an encoder-decoder: the encoder reads the source, and the decoder writes the target one token at a time.

Encoder

Turns the source tokens (x1…xn) into a sequence of continuous representations z = (z1…zn) (§3).

Decoder

Generates the output y1…ym one symbol at a time, using z and the symbols it has already produced.

How positions talk

The open question is how information moves between positions inside each stack. Before this paper: recurrence or convolution, usually with attention added between encoder and decoder.

2 · Limitation

In earlier models, linking two positions cost more the farther apart they were

The paper's §2 compares architectures by how many operations it takes to relate signals from two arbitrary positions. Drag the distance between the two positions.

From §2: the operations needed "grows in the distance between positions, linearly for ConvS2S and logarithmically for ByteNet"; the Transformer reduces this to a constant. Shown with kernel width k = 3 and an RNN (recurrent neural network)'s one step per position. Constants are illustrative; the growth rates come from the paper.

The constant path comes at a price the paper names: averaging attention-weighted positions reduces effective resolution, "an effect we counteract with Multi-Head Attention" (§2).

4 · Core idea

Keep the encoder-decoder; build every layer from attention and feed-forward blocks

The breakthrough is what is left out: no recurrence and no convolution. Six building blocks do all the work.

Multi-head self-attention

Mixes information between all positions in one step. Decks 03–06

Position-wise FFN

Transforms each token on its own. Deck 11

Add & Norm

Residual connection + layer normalization around every sub-layer. Deck 10

Positional encoding

Injects word order into the embeddings. Deck 07

Encoder-decoder attention

Lets the decoder read the source. Deck 08

Masked self-attention

Stops the decoder seeing future tokens. Deck 09

At a glance

Every sub-layer: residual connection + layer normalization; d_model = 512 throughout (base).

5 · How it works

Follow one sentence through the model: shapes at every stage

Translating a source sentence of n tokens. While training, the decoder sees the m target tokens, shifted right by one position. Every sub-layer keeps the width at dmodel = 512, which is what lets the residual connections add their input to their output.

The encoder runs once per source sentence and produces a "memory" of n × 512 vectors. Every decoder layer reads that same memory through encoder-decoder attention.

5 · How it works

Worked example: shapes through the base model

Translate a 10-token source into a 9-token target prefix. Base model: d_model = 512, 8 heads, d_ff = 2,048, N = 6, shared vocabulary of about 37,000 tokens.

Worked example

  1. Source embeddings + positional encoding: [10, 512]; every encoder layer keeps [10, 512].
  2. Target prefix (shifted right): [9, 512] through 6 decoder layers; cross-attention weights per head are [9, 10].
  3. Output projection: [9, 512] × [512, ~37,000] → [9, ~37,000] logits: one next-token distribution per target position.
  4. Parameters: base ≈ 65M, big (d_model 1,024, 16 heads, d_ff 4,096) ≈ 213M.
The width stays 512 everywhere; only attention patterns and the FFN (feed-forward network) expansion change what each position holds.
5 · How it works from the paper · §3.1, §3.4

The paper's own description

Encoder: a stack of N = 6 identical layers, each with two sub-layers: multi-head self-attention, and a simple, position-wise fully connected feed-forward network. Each sub-layer has a residual connection followed by layer normalization, so its output is LayerNorm(x + Sublayer(x)), and all outputs have dimension dmodel = 512.
Decoder: also N = 6 layers, with a third sub-layer that performs multi-head attention over the output of the encoder stack. Its self-attention is masked, and together with output embeddings offset by one position, this ensures predictions for position i can depend only on outputs at positions less than i.
Embeddings (§3.4): learned embeddings convert tokens to dmodel-dimensional vectors. The two embedding layers and the pre-softmax linear transformation share the same weight matrix, and in the embedding layers those weights are multiplied by √dmodel.
6 · Why it works

Why this design works

Constant path length

Any two positions are connected by one attention step in every layer, compared with O(n) for recurrence (Table 1). Long-range dependencies become easier to learn.

Parallel training

All positions in a layer are computed at once. The decoder stays auto-regressive through masking plus the shifted-right input, yet still trains on every position in parallel.

Easy to stack

Every sub-layer outputs dmodel = 512, so residual connections can add input to output, and N = 6 identical layers stack cleanly. Table 3 (C): N = 2 gives 23.7 BLEU (Bilingual Evaluation Understudy, an n-gram overlap score for translation), N = 6 gives 25.8.

Evidence

New state of the art on WMT (Workshop on Machine Translation) 2014 EN-DE (28.4 BLEU) and EN-FR (41.8) at a fraction of the training cost (Table 2, deck 14).

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"The original Transformer is a decoder-only model."

The 2017 model is an encoder-decoder: a 6-layer encoder and a 6-layer decoder joined by encoder-decoder attention.

"Encoder and decoder layers are identical."

Encoder layers have 2 sub-layers (self-attention, FFN). Decoder layers have 3: masked self-attention, encoder-decoder attention, FFN.

"The encoder output only feeds the first decoder layer."

Every decoder layer attends to the final encoder output through its encoder-decoder attention sub-layer.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Three attentions. Encoder self-attention, masked decoder self-attention, encoder-decoder (cross) attention.
  • Width never changes. All sub-layers in and out are d_model = 512 so residuals can add.
  • Shared embeddings. Input, output embeddings and pre-softmax projection share weights (scaled by √d_model in the input).

⚠ Traps

  • Thinking the encoder sees the target. Only the decoder sees the (shifted) target.
  • Forgetting the decoder's third sub-layer. Cross-attention sits between masked self-attention and the FFN.
  • Mixing base and big settings. Big doubles d_model and heads and uses dropout 0.3 on EN-DE.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

How many sub-layers does each decoder layer have?

3: masked multi-head self-attention, multi-head attention over the encoder output, and the position-wise FFN (§3.1).

For an n-token source, what shape leaves the base encoder?

n × 512. Every sub-layer keeps dmodel = 512. See "Follow one sentence through the model".

Why must every sub-layer output exactly dmodel = 512 dimensions?

Because each sub-layer is wrapped as LayerNorm(x + Sublayer(x)): you can only add the input to the output if their shapes match (§3.1).
9 · Key takeaway

Key takeaway

An encoder-decoder built only from attention and position-wise feed-forward sub-layers, each wrapped as LayerNorm(x + Sublayer(x)), stacked 6 deep on each side.
Say it in 30 seconds

The Transformer keeps the encoder-decoder structure but drops recurrence and convolution. Each of the 6 encoder layers has multi-head self-attention and a position-wise FFN; each of the 6 decoder layers adds masked self-attention and attention over the encoder output. Every sub-layer is LayerNorm(x + Sublayer(x)) with dmodel = 512, and sinusoidal positional encodings added to the embeddings provide word order.

Problem: recurrent and convolutional models needed more operations to relate positions the farther apart they were.
Core idea: an encoder-decoder made only of attention and position-wise FFN sub-layers, each wrapped as LayerNorm(x + Sublayer(x)), with N = 6 layers on each side, dmodel = 512.

A dilated convolutional encoder-decoder that runs in time linear in sequence length; a parallel alternative to RNNs.

A fully convolutional sequence-to-sequence model with gated linear units and per-layer attention, fully parallel in training.
