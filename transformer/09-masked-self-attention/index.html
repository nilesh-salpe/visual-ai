Attention Is All You Need · 09

Masked self-attention

How the decoder is stopped from seeing future target tokens, so a model trained on whole sentences can still generate one token at a time.

What is the problem?During training the decoder is given the whole target sentence. If position i could attend to position i+1, it would simply copy the answer.
Core ideaShift the target right by one, and set every score for a future position to −∞ before the softmax. Position i can then use only positions ≤ i.
① What is the problem?

If the decoder can see ahead, it learns to copy

The decoder input is the target shifted right (start token first), and position i must predict target token i. Unmasked self-attention lets position i read the input at position i+1, which is the token it is supposed to predict. Training would look perfect, and generation would fail because that future token doesn't exist yet.

② Core idea

Shift right + mask: position i sees only positions ≤ i

The mask is a lower-triangular pattern. Scores above the diagonal are replaced by −∞, so after the softmax their weights are exactly 0. Drag the position to see each row of the mask.

② Core idea

The masked softmax, computed live

The same scaled dot-product attention as deck 05, with one extra step between the scaling and the softmax. Step through it.

Because the mask is just −∞ entries in one matrix, all positions are still computed in parallel during training, and none of them can see the future (deck 12).
In the paper · §3.1, §3.2.3, Figure 2

The paper's wording

§3.1: "We also modify the self-attention sub-layer in the decoder stack to prevent positions from attending to subsequent positions. This masking, combined with fact that the output embeddings are offset by one position, ensures that the predictions for position i can depend only on the known outputs at positions less than i."
§3.2.3: "We need to prevent leftward information flow in the decoder to preserve the auto-regressive property. We implement this inside of scaled dot-product attention by masking out (setting to −∞) all values in the input of the softmax which correspond to illegal connections."
Figure 2: the scaled dot-product attention diagram has an optional Mask block between Scale and SoftMax.
Recap

Masked self-attention in two lines

Problem: with the full target visible in training, an unmasked decoder could copy future tokens.
Core idea: output embeddings offset by one, plus −∞ on future scores, means position i depends only on positions < i in the target, while every position is still trained in parallel.
