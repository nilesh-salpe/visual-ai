Attention Is All You Need · 03

Self-attention

How each token builds a context-aware representation by drawing on every other token in the same sequence.

What is the problem?A word's embedding is the same whatever sentence it's in, but its meaning depends on context. "It" refers to different things in different sentences.
Core ideaEach token computes a weighted average over all tokens in the sequence. The weights express relevance, so the output for "it" draws mostly on the word it refers to.
① What is the problem?

Same word, same vector, different meaning

An embedding table gives "it" one fixed vector. In the first sentence "it" means the animal; in the second it means the street. Something has to mix in context.

Example sentences are illustrative and do not come from the paper. Vector values are toy numbers.

For the model to resolve "it", the representation of "it" has to depend on the other words in the sentence.
② Core idea

Each token takes a weighted mix of every token in the sentence illustrative weights

Self-attention relates different positions of a single sequence to compute a new representation of it. Click a token to see where it attends. Arc thickness is the attention weight, and the weights for each token add up to 1.

The output for "it" is mostly built from "animal" (or "street"), so the same input word ends up with different, context-aware representations.
② Core idea

All tokens do this at once: an n × n attention matrix illustrative weights

Row i is token i's attention distribution over every token. All rows are computed in parallel with a few matrix multiplications, and nothing waits on a previous step. Hover a row.

Hover a row of the matrix.
Each row sums to 1 because it comes from a softmax. Deck 05 shows how the weights are computed: softmax(QKᵀ/√dk).

In the paper · §2, §3.2, §3.2.3

The definitions

Self-attention (§2): "sometimes called intra-attention, is an attention mechanism relating different positions of a single sequence in order to compute a representation of the sequence."
Attention function (§3.2): maps a query and a set of key-value pairs to an output. The output is a weighted sum of the values, where each weight comes from a compatibility function of the query with the matching key.
In the encoder (§3.2.3): all of the keys, values and queries come from the output of the previous encoder layer, so each position can attend to all positions in the previous layer.

Recap

Self-attention in two lines

Problem: a fixed embedding can't express that a word's meaning depends on context ("it" → animal or street).
Core idea: each token's output is a relevance-weighted mix of all tokens in the same sequence, computed for all positions in parallel.
