Attention Is All You Need · 03

Self-attention

How each token builds a context-aware representation by drawing on every other token in the same sequence.

What is the problem?A word's embedding is the same whatever sentence it's in, but its meaning depends on context. "It" refers to different things in different sentences.
Core ideaEach token computes a weighted average over all tokens in the sequence. The weights express relevance, so the output for "it" draws mostly on the word it refers to.
1 · Problem

Same word, same vector, different meaning

An embedding table gives "it" one fixed vector. In the first sentence "it" means the animal; in the second it means the street. Something has to mix in context.

Example sentences are illustrative and do not come from the paper. Vector values are toy numbers.

For the model to resolve "it", the representation of "it" has to depend on the other words in the sentence.
2 · Limitation

Existing ways of adding context are slow, local, or absent

Embedding lookup

No context at all: "it" gets the same vector in every sentence.

Recurrence

Context arrives through a chain of hidden states: n sequential steps, and O(n) hops between distant words (deck 01).

Convolution

Sees a fixed window of k tokens. Linking distant words needs a stack of O(n/k) layers, or O(logk n) with dilated convolutions (§4).

What's missing: a way for each word to draw on any other word in the sentence directly, chosen by relevance rather than by distance.

4 · Core idea

Each token takes a weighted mix of every token in the sentence illustrative weights

Self-attention relates different positions of a single sequence to compute a new representation of it. Click a token to see where it attends. Arc thickness is the attention weight, and the weights for each token add up to 1.

The output for "it" is mostly built from "animal" (or "street"), so the same input word ends up with different, context-aware representations.

At a glance

Each output is a weighted average of all the inputs, with weights computed from the data.

5 · How it works

All tokens do this at once: an n × n attention matrix illustrative weights

Row i is token i's attention distribution over every token. All rows are computed in parallel with a few matrix multiplications, and nothing waits on a previous step. Hover a row.

Hover a row of the matrix.
Each row sums to 1 because it comes from a softmax. Deck 05 shows how the weights are computed: softmax(QKᵀ/√dk).
5 · How it works

Worked example: one row of attention

Three tokens; the query token scores the three keys as [2, 1, 0]. Values are v₁ = [1, 0], v₂ = [0, 1], v₃ = [1, 1].

Worked example

  1. softmax([2, 1, 0]) = [0.665, 0.245, 0.090].
  2. Output = 0.665·[1,0] + 0.245·[0,1] + 0.090·[1,1] = [0.755, 0.335].
  3. Every token does this at once: a 3 × 3 weight matrix times the value matrix.
  4. The weights change with every sentence: same word, different context, different output.
Self-attention is a data-dependent weighted average: the weights are the "who to look at", the values are the "what to take".
5 · How it works from the paper · §2, §3.2, §3.2.3

The definitions

Self-attention (§2): "sometimes called intra-attention, is an attention mechanism relating different positions of a single sequence in order to compute a representation of the sequence."
Attention function (§3.2): maps a query and a set of key-value pairs to an output. The output is a weighted sum of the values, where each weight comes from a compatibility function of the query with the matching key.
In the encoder (§3.2.3): all of the keys, values and queries come from the output of the previous encoder layer, so each position can attend to all positions in the previous layer.

6 · Why it works

Why it works

Context-dependent by construction

The weights are computed from the actual sentence, so the same word gets different outputs in different contexts ("it" → animal vs street).

One hop to anything

Every token reaches every other token in a single step, so distance doesn't weaken the connection (path length O(1)).

All positions in parallel

The whole n × n weight matrix comes out of matrix products, with no step-by-step dependency.

Learned, not hand-designed

What to attend to is learned from data. The trained model's heads end up tracking real linguistic structure, as the next slide shows.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Attention weights show which words are important in the sentence."

They are per-query mixing weights in one head of one layer: how much a given token takes from each other token. Different heads and layers attend differently (Figure 5). They are not a global importance score.

"Self-attention compares the raw word embeddings directly."

It compares learned query and key projections of the embeddings and mixes learned value projections (deck 04).

"A token cannot attend to itself."

It can and usually does: the diagonal of the attention matrix is typically non-zero. The token's own value is part of its mix.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Rows sum to 1. Each output is a convex combination of values.
  • n × n matrix. One row per query, one column per key.
  • Permutation-equivariant. Shuffle inputs and outputs shuffle the same way; order needs positional encoding.

⚠ Traps

  • Attention weights as explanations. They show mixing, not necessarily causal importance.
  • Forgetting values. Weights come from Q·K; content comes from V.
  • Assuming symmetric attention. Token i attending to j says nothing about j attending to i.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

In encoder self-attention, where do the queries, keys and values come from?

All three from the previous encoder layer (§3.2.3), so each position can attend to all positions of that layer.

What does each row of the attention matrix sum to?

1, because each row comes from a softmax: it is one token's distribution over all tokens.

"it" has the same embedding in the "tired" and "wide" sentences. How can self-attention give it different outputs?

The weights depend on the other tokens in the sentence: "tired" vs "wide" changes how well "animal" and "street" match "it", so the weighted mix and the output change.
9 · Key takeaway

Key takeaway

Each token's new representation is a relevance-weighted average of all tokens in the same sequence, so context changes what a word means.
Say it in 30 seconds

Self-attention lets every position look at every other position of the same sequence. For each token it computes weights over all tokens, summing to 1, and outputs the weighted sum of their value vectors, so "it" can draw mostly from "animal". All positions are computed in parallel with matrix products, and any two tokens are one hop apart.

Problem: a fixed embedding can't express that a word's meaning depends on context ("it" → animal or street).
Core idea: each token's output is a relevance-weighted mix of all tokens in the same sequence, computed for all positions in parallel.
