Why the Transformer works

How four ingredients together address the limits of recurrent sequence models: direct token-to-token connections, multiple heads, positional information, and stacked layers.

What is the problem?Recurrent models are slow to train (sequential), struggle with long-range dependencies (long paths), and capture all relationships through one hidden state.
Core ideaEach ingredient fixes one limit. The paper's ablations (Table 3) measure how much each design choice matters.
1 · Problem

Sequence models were slow to train and struggled with long-range structure

Speed

Recurrent models need n sequential steps per layer, which limits how much data and how many experiments you can afford.

Long-range structure

Dependencies between distant words have to cross long paths.

Many relationships

Reference, syntax and agreement all have to be captured at once.

2 · Limitation

Three criteria that recurrent layers score poorly on

§4 compares layer types on three criteria. For translation-length sequences (n < d), recurrence loses on all three.

Parallelism

Sequential operations per layer: RNN (recurrent neural network) O(n) vs self-attention O(1). Training time grows with sequence length.

Long-range paths

Maximum path length: RNN O(n) vs self-attention O(1). Distant dependencies are harder to learn.

Compute per layer

RNN O(n·d²) vs self-attention O(n²·d). Self-attention is cheaper when n < d, as in sentence-level translation with BPE (byte-pair encoding).

Attention fixes parallelism and path length, but on its own it brings two new problems: it is order-blind, and averaging blurs distinct relationships. The other ingredients address those.

5 · How it works

Worked example: reading the ablations (Table 3, newstest2013)

Base: perplexity 4.92, BLEU 25.8. Each row changes one setting.

Worked example

  1. Single head (h = 1): BLEU 24.9 → multiple heads matter.
  2. Smaller keys (d_k = 16): BLEU 25.1 → compatibility needs enough dimensions.
  3. No label smoothing (ε_ls = 0): perplexity improves to 4.67 but BLEU falls to 25.3.
  4. Learned instead of sinusoidal positions: BLEU 25.7 → nearly identical.
The evidence supports multi-head attention and adequate key size; the specific position encoding mattered little.
6 · Why it works from the paper · §4, §6.2, §7

The paper's own conclusions

§6.2 (A): "While single-head attention is 0.9 BLEU worse than the best setting, quality also drops off with too many heads."
§6.2 (B): "Reducing the attention key size dk hurts model quality. This suggests that determining compatibility is not easy and that a more sophisticated compatibility function than dot product may be beneficial."
§6.2 (C, D, E): "Bigger models are better, and dropout is very helpful in avoiding over-fitting." Replacing sinusoids with learned positional embeddings gives "nearly identical results".
§7: the Transformer is "the first sequence transduction model based entirely on attention", and "can be trained significantly faster than architectures based on recurrent or convolutional layers."
7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

""Attention is all you need" means the model is only attention."

The model also depends on position-wise FFNs, residual connections, layer normalization, positional encodings and embeddings. The title means no recurrence and no convolution.

"In Table 3, bigger is always better."

Bigger dmodel and dff helped, but too many heads (h = 32) hurt, and removing dropout hurt (24.6 BLEU).

"The gains come from one key trick."

Table 3 shows many design choices each matter: heads, key size, depth, width, dropout and label smoothing.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Read ablations as one-change-at-a-time. Compare each row with the base row.
  • Perplexity ≠ BLEU. Label smoothing hurts perplexity but helps BLEU.
  • Dev set. Table 3 uses newstest2013, not the test set.

⚠ Traps

  • Over-reading small differences. A 0.1 BLEU change is within run-to-run noise.
  • Generalizing to LLMs (large language models) directly. These are translation models at 65M parameters.
  • Treating attention maps as proof. They are suggestive, not causal explanations.

9 · Key takeaway

Key takeaway

Direct attention for speed and reach, multiple heads for several relationships, positional encoding for order, and residual stacks with FFNs for depth. Table 3 shows each one matters.
Say it in 30 seconds

The Transformer works because each ingredient fixes a specific weakness. Self-attention makes layers fully parallel with O(1) paths between any two tokens. Multiple heads counteract the blurring from averaging. Positional encodings supply the order that attention ignores. Residual connections, layer normalization and position-wise FFNs make a deep stack trainable and expressive. The paper's ablations back this up: one head, a smaller dk, fewer layers or no dropout all lower BLEU.

Problem: recurrence is sequential, uses long paths between distant tokens, and squeezes all relationships into one state.
Core idea: direct attention (parallel, O(1) paths) + multiple heads (several relationships) + positional encoding (order) + stacked residual layers with FFNs (depth), each backed by the Table 3 ablations.

Attention Is All You Need
Vaswani et al. · NeurIPS 2017

The Transformer: attention-only encoder-decoder with post-norm residual blocks, sinusoidal positions and a ReLU (rectified linear unit) FFN (feed-forward network). The baseline every later change is measured against.

Remember: 28.4 BLEU on WMT (Workshop on Machine Translation) 2014 English-German
Are Sixteen Heads Really Better than One?
Michel et al. · NeurIPS 2019

Finds that a large percentage of attention heads can be removed at test time without much loss; some layers work with a single head.

Self-Attention with Relative Position Representations
Shaw et al. · NAACL 2018

Adds learned relative-distance representations inside self-attention instead of absolute position vectors at the input.

Remember: +1.3 BLEU (EN-DE) and +0.3 BLEU (EN-FR) over absolute positions
