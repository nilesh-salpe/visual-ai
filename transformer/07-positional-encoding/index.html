Attention Is All You Need · 07

Positional encoding

Why attention needs explicit information about token order, and how fixed sinusoids at different frequencies provide it.

What is the problem?Self-attention treats its input as a set. Shuffle the words and each word gets exactly the same output, so "dog bites man" and "man bites dog" look alike.
Core ideaAdd a position-dependent vector PE(pos) to each embedding: sines and cosines whose wavelengths form a geometric progression from 2π to 10000·2π.
1 · Problem

Word order carries meaning

Who did what

"dog bites man" and "man bites dog" use the same words with opposite meanings.

Translation reorders

German often moves the verb to the end of a clause, so the model must track where each word sits.

Relative position matters

"not" changes the word right after it; adjectives modify the noun next to them.

Any sequence model must know where each token is, and how far apart two tokens are.
2 · Limitation

Without position information, word order doesn't change anything

Self-attention computes softmax(QKᵀ/√dk)V. Nothing in that formula depends on where a token is. Reorder the input and every token's output stays the same; only the order of the output rows changes. Below is a live toy self-attention (d = 4).

"The model contains no recurrence and no convolution", so the order has to be injected some other way (§3.5).

B. The paper adds a dmodel-dimensional positional encoding to each embedding. A raw integer (A) grows without bound and sits on a very different scale from the other features. Sorting (C) destroys order. The mask (D) exists only in the decoder and only blocks future positions; it doesn't say where a token is.
4 · Core idea

Add a position vector to each word vector

PE has the same dimension as the embeddings (dmodel = 512), so the two can be summed. This happens once, at the bottom of both the encoder and decoder stacks, and dropout is applied to the sum.

PE(pos, 2i) = sin(pos / 100002i/dmodel)    PE(pos, 2i+1) = cos(pos / 100002i/dmodel)
5 · How it works

Every dimension is a sinusoid with its own wavelength

Low dimensions oscillate quickly and high dimensions slowly. The wavelengths form a geometric progression from 2π to 10000·2π, so every position gets a unique pattern, a bit like the hands of a clock running at many speeds.

5 · How it works

Why sinusoids: a fixed offset k is a fixed rotation

For each frequency ω, the pair (sin ωp, cos ωp) is a point on a circle. Moving k positions rotates it by the angle ωk, whatever p is, so PE(pos+k) is a linear function of PE(pos). The authors hypothesized this would make it easy to attend by relative position.

Similarity PE(p)·PE(q), positions 0–63

The dot product depends only on the distance |p − q|: the same pattern along every diagonal.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"The positional encoding is concatenated to the embedding."

It is added. PE has the same dimension dmodel as the embedding "so that the two can be summed" (§3.5).

"Positional encodings are added in every layer."

They are added once, "at the bottoms of the encoder and decoder stacks" (§3.5). Residual connections carry them upward.

"Sinusoids were shown to beat learned position embeddings."

The two gave nearly identical results (Table 3 E: 25.7 vs 25.8 BLEU). Sinusoids were chosen because they may extrapolate to longer sequences.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

What range do the PE wavelengths span?

A geometric progression from 2π to 10000·2π (§3.5).

What is the positional encoding at position 0?

Every even dimension is sin(0) = 0 and every odd dimension is cos(0) = 1.

Without positional encoding, what happens to the encoder's per-token outputs if you shuffle the input words?

Each word gets exactly the same output, just in a different row order. Self-attention is permutation-invariant (see the "dog bites man" demo).
9 · Key takeaway

Key takeaway

Add a fixed sinusoidal code PE(pos) to every embedding, so attention can tell positions apart and a fixed offset becomes a fixed rotation.
