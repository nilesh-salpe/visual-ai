Attention Is All You Need · 01

The sequential processing bottleneck

Why recurrent networks read one token at a time, why that limits parallel computation and makes long-range dependencies hard to learn, and how self-attention removes both limits.

What is the problem?An RNN (recurrent neural network) computes ht from ht−1, so a sentence of n tokens takes n sequential steps, and signals between distant words must pass through many steps.
Core ideaSelf-attention connects every pair of positions directly: O(1) sequential operations and O(1) path length per layer.
1 · Problem

A sequence model must connect distant words and train fast on a lot of data

Translation is the paper's test bed. A good model has to do three things at once.

Relate distant words

In "The animal didn't cross the street because it was tired", resolving "it" needs a link across 6 words. Long-range dependencies are "a key challenge in many sequence transduction tasks" (§4).

Learn from a lot of data

WMT (Workshop on Machine Translation) 2014 English-German has about 4.5 million sentence pairs; English-French has 36 million sentences (§5.1). Training speed decides what you can afford to try.

Use parallel hardware

GPUs (graphics processing units) run thousands of operations at the same time. Training is only fast if the work can be split across positions.

The architecture should make any two positions easy to connect, and let all positions be computed at the same time.
2 · Limitation

An RNN must wait for step t−1 before it can compute step t

A recurrent layer computes the hidden state ht = f(ht−1, xt). Each step needs the result of the previous one, so the steps run one after another, even on hardware that could run thousands of operations at the same time.

hidden state computedwaiting on the previous stepparallel hardware lane busy
Training on long sequences is slow because time steps can't run in parallel. Batching across sentences helps, but memory limits how far that goes for long sequences (§1 of the paper).
Paper §1: "This inherently sequential nature precludes parallelization within training examples, which becomes critical at longer sequence lengths."
2 · Limitation

Distant words are many steps apart

To link "it" to "animal", information has to travel through every hidden state in between. A longer path makes the dependency harder to learn: the forward signal and the backward gradient both pass through many transformations. Click two tokens.

C is the paper's move. A bigger state (A) or more layers (D) keeps the n-step chain. A bidirectional RNN (B) still needs n sequential steps and long paths in each direction. Only direct position-to-position connections give O(1) sequential operations and O(1) path length (Table 1).
4 · Core idea

Self-attention connects every position to every other in one step

In a self-attention layer, every token reads from every other token directly, and all positions are computed at the same time. Switch between the two layer types.

Both problems from the previous slides go away: the whole layer is computed in parallel, and any two tokens are one hop apart.

5 · How it works

A loop of n dependent steps vs a few matrix products

The difference shows up directly in code. A recurrent layer is a loop where each step needs the previous one. A self-attention layer is a handful of matrix products over all positions at once.

Recurrent layer

h = h0
for t in range(n):        # n dependent steps
h = f(h, x[t])        # needs h from step t-1
out[t] = h

Self-attention layer

Q, K, V = X@Wq, X@Wk, X@Wv  # all n positions
S = Q @ K.T / sqrt(d_k)     # n×n scores: 1 matmul
A = softmax(S, axis=-1)     # each row sums to 1
out = A @ V                 # all n outputs at once
Every output row depends on all inputs, but no output depends on another output, so the whole layer runs in parallel. Decks 03–05 explain each line.
6 · Why it works

The cost: self-attention compares every pair, n² · d

Connecting every pair costs O(n²·d) per layer, versus O(n·d²) for recurrence. The paper points out that self-attention is cheaper when n < d, which was typical for sentence-level translation with word-piece or BPE (byte-pair encoding) tokens.

Operation counts per layer from Table 1's complexity terms, without constants: self-attention n²·d, recurrent n·d², convolutional k·n·d². The paper's base model uses d = 512.

5 · How it works

Worked example: recurrent vs self-attention cost for one layer

A sentence of n = 50 tokens, model width d = 512 (the base Transformer).

Worked example

  1. Self-attention: n² · d = 50² × 512 = 1.28M operations, with O(1) sequential steps.
  2. Recurrent layer: n · d² = 50 × 512² = 13.1M operations, with 50 sequential steps.
  3. Maximum path length between two words: self-attention 1; RNN up to 49.
  4. Break-even: self-attention is cheaper whenever n < d, i.e. sentences shorter than 512 tokens (the paper's Table 1 argument).
For typical sentence lengths, self-attention is both cheaper per layer and fully parallel.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Self-attention is always cheaper than a recurrent layer."

Per layer, self-attention costs O(n²·d) and recurrence O(n·d²). Self-attention is cheaper only when n < d, which the paper notes is usually true for sentence-level translation. For very long sequences it suggests restricting attention to a neighbourhood of size r (§4).

"The Transformer has no sequential computation at all."

Within a layer, all positions run in parallel. But the 6 layers still run one after another, and generation is still one token at a time (deck 12).

"RNNs can't learn long-range dependencies."

They can (LSTMs (long short-term memory networks) were the state of the art). The paper's argument is that longer paths make it harder: shorter paths between positions make long-range dependencies easier to learn (§4).
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Table 1 in one line. Self-attention O(n²·d), O(1) sequential, path 1; recurrent O(n·d²), O(n) sequential, path n.
  • Self-attention wins when n < d. Typical in translation sentences.
  • Parallel over positions in training. All n outputs computed in one pass.

⚠ Traps

  • "Attention is always cheaper." For very long n, n² dominates; that is why long-context methods exist.
  • Confusing training and generation. Generation is still sequential, one token per step.
  • Forgetting path length. Short paths are the long-range-dependency argument, not just speed.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

What is the maximum path length between two positions in a recurrent layer (Table 1)?

O(n). Information must pass through every hidden state in between. Self-attention: O(1). See "Distant words are many steps apart".

For n = 50 tokens and d = 512, which layer is cheaper per layer, self-attention or recurrent, and by roughly how much?

Self-attention: n²·d = 50² × 512 ≈ 1.3M. Recurrent: n·d² = 50 × 512² ≈ 13.1M. Self-attention is about 10× cheaper, because n < d.

Why doesn't batching many sentences together fix the RNN bottleneck?

Batching parallelizes across sentences, but within each sentence the steps stay sequential, and memory limits how large batches can get for long sequences (§1).
9 · Key takeaway

Key takeaway

Recurrence pushes computation and information through n sequential steps. Self-attention puts every pair of positions one hop apart and computes them all at once.
Say it in 30 seconds

RNNs compute ht from ht−1, so a layer needs O(n) sequential steps and distant tokens are O(n) hops apart. That makes training slow and long-range dependencies hard to learn. Self-attention connects all positions directly: O(1) sequential operations and O(1) path length per layer, at O(n²·d) cost, which is cheaper than recurrence's O(n·d²) when n < d, as in sentence-level translation.

Problem: recurrence forces n sequential steps per layer, and puts O(n) hops between distant tokens.
Core idea: self-attention computes all positions at once with O(1) path length, at O(n²·d) cost, which is cheaper than recurrence when n < d.
