Attention Is All You Need · 01

The sequential processing bottleneck

Why recurrent networks read one token at a time, why that limits parallel computation and makes long-range dependencies hard to learn, and how self-attention removes both limits.

What is the problem?An RNN computes ht from ht−1, so a sentence of n tokens takes n sequential steps, and signals between distant words must pass through many steps.
Core ideaSelf-attention connects every pair of positions directly: O(1) sequential operations and O(1) path length per layer.
① What is the problem?

An RNN must wait for step t−1 before it can compute step t

A recurrent layer computes the hidden state ht = f(ht−1, xt). Each step needs the result of the previous one, so the steps run one after another, even on hardware that could run thousands of operations at the same time.

hidden state computedwaiting on the previous stepparallel hardware lane busy
Training on long sequences is slow because time steps can't run in parallel. Batching across sentences helps, but memory limits how far that goes for long sequences (§1 of the paper).
Paper §1: "This inherently sequential nature precludes parallelization within training examples, which becomes critical at longer sequence lengths."
① What is the problem?

Distant words are many steps apart

To link "it" to "animal", information has to travel through every hidden state in between. A longer path makes the dependency harder to learn: the forward signal and the backward gradient both pass through many transformations. Click two tokens.

The paper's third criterion is the path length between long-range dependencies: "The shorter these paths … the easier it is to learn long-range dependencies" (§4).
② Core idea

Self-attention connects every position to every other in one step

In a self-attention layer, every token reads from every other token directly, and all positions are computed at the same time. Switch between the two layer types.

Both problems from the previous slides go away: the whole layer is computed in parallel, and any two tokens are one hop apart.
② Core idea

The cost: self-attention compares every pair, n² · d

Connecting every pair costs O(n²·d) per layer, versus O(n·d²) for recurrence. The paper points out that self-attention is cheaper when n < d, which was typical for sentence-level translation with word-piece or BPE tokens.

Operation counts per layer from Table 1's complexity terms, without constants: self-attention n²·d, recurrent n·d², convolutional k·n·d². The paper's base model uses d = 512.

Recap

Sequential bottleneck in two lines

Problem: recurrence forces n sequential steps per layer, and puts O(n) hops between distant tokens.
Core idea: self-attention computes all positions at once with O(1) path length, at O(n²·d) cost, which is cheaper than recurrence when n < d.
