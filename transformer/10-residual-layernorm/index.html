Residual connections and layer normalization

How every sub-layer is wrapped as LayerNorm(x + Sublayer(x)) so information and gradients flow through a stack of 6 + 6 layers.

What is the problem?Stacking many sub-layers makes training hard. Each one transforms the signal, so the original information and the gradients can fade or blow up with depth.
Core ideaAdd each sub-layer's output back to its input (a residual, or skip, connection), then normalize each token's vector to zero mean and unit variance across its features.
1 · Problem

The model is deep: 12 sub-layers in the encoder, 18 in the decoder

Encoder

6 layers × 2 sub-layers = 12 transformations in a row.

Decoder

6 layers × 3 sub-layers = 18 transformations in a row.

Depth helps

Table 3 (C): N = 2 gives 23.7 dev BLEU (Bilingual Evaluation Understudy, an n-gram overlap score for translation), N = 6 gives 25.8.

The architecture needs depth, so signals and gradients must pass cleanly through many stacked sub-layers.

4 · Core idea

Every sub-layer is wrapped the same way

The input x skips around the sub-layer and is added to its (dropout-regularized) output, and the sum is then layer-normalized. The paper places the normalization after the addition. All widths are dmodel = 512 so the addition works.

Skip path

The identity route lets information (and gradients) pass unchanged. The sub-layer only has to learn a correction to x.

Dropout 0.1

Applied to each sub-layer's output before the addition (§5.4, residual dropout).

LayerNorm

Re-centres and re-scales each token's 512 features, keeping activations in a stable range from layer to layer.

At a glance

LayerNorm(x + Sublayer(x)) around all 12 encoder and 18 decoder sub-layers.

5 · How it works

Layer normalization works on one token's features

For a single token vector: subtract its mean μ, divide by its standard deviation σ, then apply a learned gain γ and bias β. It never looks across other tokens or other examples. Scale or shift the input to see that the normalized output doesn't change.

LN(x) = γ ⊙ (x − μ) / σ + β,   μ = mean over the 512 features of one token
5 · How it works

Worked example: LayerNorm on one token

A token with 4 features [2.0, -1.0, 0.5, 3.5] (gain 1, bias 0).

Worked example

  1. Mean = 1.250; standard deviation = 1.677.
  2. Normalized = (x − mean) / std = [0.45, -1.34, -0.45, 1.34].
  3. The result has mean 0 and variance 1 regardless of the input scale, so stacked layers stay in range.
  4. It uses only this token's features, so it behaves the same at any batch size (unlike BatchNorm).
Residuals keep a clean path for gradients; LayerNorm keeps each token's scale stable through 30 sub-layers.
5 · How it works from the paper · §3.1, §5.4

The paper's wording

§3.1: "We employ a residual connection [11] around each of the two sub-layers, followed by layer normalization [1]. That is, the output of each sub-layer is LayerNorm(x + Sublayer(x)), where Sublayer(x) is the function implemented by the sub-layer itself. To facilitate these residual connections, all sub-layers in the model, as well as the embedding layers, produce outputs of dimension dmodel = 512."
§5.4, Residual Dropout: dropout is applied to the output of each sub-layer before it is added to the sub-layer input and normalized, and also to the sums of the embeddings and positional encodings. Pdrop = 0.1 for the base model.
Table 3 (D): Pdrop = 0.0 gives 24.6 BLEU (dev) against 25.8 for the base model, so "dropout is very helpful in avoiding over-fitting" (§6.2).
6 · Why it works

Why it works

Identity path

x reaches the output unchanged, plus a learned correction. Information and gradients have a direct route through the whole stack.

Stable scale

LayerNorm re-centres and re-scales each token's features after every sub-layer, so activations don't drift with depth.

Regularized corrections

Dropout on each sub-layer output before the add. Table 3 (D): Pdrop = 0 gives 24.6 BLEU vs 25.8 with 0.1.

One width everywhere

All sub-layers and embeddings output dmodel = 512, so every residual addition lines up (§3.1).

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Layer normalization normalizes across the batch."

It normalizes across the features of one token (its 512 values). Normalizing across the batch is batch normalization, a different technique.

"The paper applies LayerNorm before each sub-layer."

The paper uses LayerNorm(x + Sublayer(x)): normalization comes after the residual addition (§3.1).

"Residual connections add parameters."

The skip path is the identity: no parameters. LayerNorm adds only a gain and bias per feature.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Sub-layer counts. Encoder 6 × 2 = 12; decoder 6 × 3 = 18.
  • Per-token normalization. Mean and variance over the 512 features.
  • Modern change. Later models moved the norm inside the branch (pre-norm) and used RMSNorm (root-mean-square normalization).

⚠ Traps

  • Calling it BatchNorm. LayerNorm ignores other examples in the batch.
  • Forgetting dropout. Applied to each sub-layer output before the residual add.
  • Assuming post-norm trains easily. It needed warm-up (4,000 steps in the paper).

Check yourself

What is the output of each sub-layer in the paper?

LayerNorm(x + Sublayer(x)) (§3.1), with dropout applied to Sublayer(x) before the addition.

Where is residual dropout applied?

To each sub-layer output before the add & norm, and also to the sums of embeddings and positional encodings (§5.4).

Why must every sub-layer output exactly 512 dimensions?

So that x + Sublayer(x) is defined: you can only add vectors of the same size.
9 · Key takeaway

Key takeaway

Wrap every sub-layer as LayerNorm(x + Sublayer(x)): the skip path carries information through, and normalization keeps each token's scale stable.
Say it in 30 seconds

Each of the Transformer's sub-layers, whether attention or FFN (feed-forward network), is wrapped in a residual connection followed by layer normalization: output = LayerNorm(x + Dropout(Sublayer(x))). The identity path lets information and gradients flow through the 12-to-18-sub-layer stacks, so each sub-layer only learns a correction. LayerNorm normalizes each token's 512 features to keep activations stable, and all widths are 512 so the additions line up.

Problem: deep stacks of transformations make the signal and gradients drift, fade or explode.
Core idea: output = LayerNorm(x + Dropout(Sublayer(x))). The skip path carries x through unchanged, and LN (layer normalization) keeps each token's features centred and scaled.
