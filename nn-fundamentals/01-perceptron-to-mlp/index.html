Neural Networks · 01

From perceptron to MLP

Why a single neuron can only draw a straight line, how one hidden layer with a nonlinearity fixes that, and why depth is the backbone of every LLM (large language model) block.

What is the problem?A single linear unit computes w·x + b and thresholds it: one straight boundary. Many simple patterns, starting with XOR (exclusive or), cannot be separated by any straight line.
Core ideaStack layers: a hidden layer h = φ(xW₁ + b₁) with a nonlinearity φ, then an output layer on h. The hidden layer re-maps the inputs so a straight boundary works in its space. With enough hidden units one layer can approximate any continuous function (universal approximation).
1 · Problem

One line can't separate XOR

In input space, rotate and shift a straight decision boundary: no setting gets all four XOR points right. Switch to the hidden space of a 2-unit ReLU (rectified linear unit) layer and the same points become separable.

Hidden layer: h₁ = ReLU(x₁ + x₂), h₂ = ReLU(x₁ + x₂ − 1). Teal = label 1, orange = label 0.

2 · Limitation

The limits of a single neuron

One straight boundary

A perceptron thresholds w·x + b, so it can only separate classes with a hyperplane.

Hand-made features don't scale

You could add x₁·x₂ by hand for XOR, but real tasks need features nobody can design.

Stacking linear layers doesn't help

W₂(W₁x) = (W₂W₁)x: still one linear map.

4 · Core idea

The multilayer perceptron

Hidden layer

h = φ(xW₁ + b₁): each unit is a learned feature, a dot product followed by a nonlinearity.

Output layer

y = hW₂ + b₂, a linear read-out of the learned features (then softmax for classification).

Universal approximation

One hidden layer with enough units approximates any continuous function on a bounded domain (Cybenko; Hornik et al., 1989).

At a glance

A transformer's MLP (multilayer perceptron) block is exactly this: up-projection, nonlinearity, down-projection.

5 · How it works

Where MLPs live inside an LLM

PieceShapeWhat it does
MLP up-projectiond → 4d (or ≈ 8d/3 ×2 for SwiGLU (Swish-gated linear unit))creates many candidate features per token
Nonlinearityelementwise (GELU (Gaussian Error Linear Unit), SiLU (Sigmoid Linear Unit) gate)lets features be non-linear functions of the input
MLP down-projection4d → dwrites the selected features back to the residual stream
Share of parameters8d² of ≈ 12d² per layerabout two thirds of a standard transformer's weights

Depth vs width

One wide layer can approximate anything in principle, but some functions need exponentially many units at depth 1 and only polynomially many with more layers. LLMs stack dozens of blocks, each with attention and an MLP.

5 · How it works

Worked example: XOR with two hidden ReLUs

Inputs (0,0), (0,1), (1,0), (1,1) with labels 0, 1, 1, 0.

Worked example

  1. Any line w·x + b = 0 gets at most 3 of the 4 points right; notebook 02 checks 20,000 random lines and the best is exactly 75%.
  2. Hidden units: h₁ = ReLU(x₁ + x₂), h₂ = ReLU(x₁ + x₂ − 1). The four points map to (0,0), (1,0), (1,0), (2,1).
  3. Output y = h₁ − 2h₂ gives 0, 1, 1, 0: XOR solved, because in (h₁, h₂) space a straight line separates the classes.
  4. Learning it from a random start: with 2 hidden units gradient descent solved XOR in 9 of 20 runs; with 8 hidden units, 20 of 20 (notebook 02).
The nonlinearity lets the hidden layer bend the space; extra width makes the solution easier to find, not just possible.
6 · Why it works

Why hidden layers work

Learned features

Training chooses W₁ so the hidden units become whatever features make the output's job easy.

Composable

Each layer's features are built from the previous layer's: edges → shapes → objects, or tokens → phrases → meaning.

Trainable end to end

Backpropagation (deck 03) gives gradients for every layer at once.

Over-parameterisation helps

Extra hidden units make gradient descent find good solutions far more reliably (notebook 02).

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Neural networks are just big logistic regressions."

Logistic regression is the last layer; the hidden layers learn the features it uses, which is the whole point.

"Universal approximation means any network can learn anything."

It says a suitable network exists, not that gradient descent will find it or that it is small.

"Each neuron detects one human-meaningful concept."

Features are often distributed across many units and units mix several features.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Linear layers compose to one linear layer. Nonlinearities are what make depth useful.
  • Width helps optimisation. Over-parameterised networks find good solutions more reliably.
  • The transformer MLP is a 2-layer MLP. d → 4d → d (or a gated SwiGLU variant).

⚠ Traps

  • Reading universal approximation as "one layer is enough in practice". It may need exponentially many units; depth is far more efficient.
  • Forgetting the bias. Without b, every boundary passes through the origin.
  • Symmetric initialisation. Identical hidden units get identical gradients and never differentiate.

9 · Key takeaway

Key takeaway

A hidden layer with a nonlinearity learns new features in which a straight boundary works; stacking such layers is the core of every neural network, including each LLM block's MLP.
Say it in 30 seconds

A single neuron computes a weighted sum and thresholds it, so it can only draw one straight boundary, and some patterns such as XOR cannot be separated that way. Adding a hidden layer with a nonlinearity changes that: the hidden units compute new features, and in their space a straight line works. With enough hidden units one layer can approximate any continuous function, but deep stacks do it far more efficiently. Without the nonlinearity, stacked linear layers collapse into one. The MLP inside every transformer block is exactly this: project up, apply a nonlinearity, project down.

Problem: one neuron = one straight boundary.
Core idea: hidden layer + nonlinearity learns features.
In LLMs: the d → 4d → d MLP in every block.

Key papers

The primary sources behind this deck, each with what it contributed. Links go to the paper (arXiv or the conference page).

Learning representations by back-propagating errors
Rumelhart, Hinton & Williams · Nature 1986

Backpropagation: apply the chain rule backward through a network to get every weight's gradient, so hidden units learn useful internal features.

Multilayer feedforward networks are universal approximators
Hornik, Stinchcombe & White · Neural Networks 1989

One hidden layer with enough units and a squashing nonlinearity can approximate any continuous function on a compact set to any accuracy.

Approximation by superpositions of a sigmoidal function
Cybenko · Mathematics of Control, Signals and Systems 1989

Proves universal approximation for single-hidden-layer networks with sigmoid units.
