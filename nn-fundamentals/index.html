Neural network fundamentals for LLMs

The deep-learning machinery every LLM (large language model) is built from: neurons and MLPs (multilayer perceptrons), activations, backpropagation, losses, optimizers and schedules, initialization, normalization and residuals, regularization, embeddings, and a first language model. Every deck follows the 9-beat template and has an interactive widget.
