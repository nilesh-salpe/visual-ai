Normalization and residual connections

The two tricks that let networks hundreds of layers deep train reliably: rescale activations at every layer, and add each layer's output to its input instead of replacing it.

What is the problem?Even with good initialisation, activation scales drift during training, and gradients must pass back through every layer of a very deep stack.
Core ideaNormalization rescales each token's (LayerNorm, RMSNorm (root-mean-square normalization)) or each feature's (BatchNorm) activations to a fixed scale, with learned gains. Residual connections compute x + f(x), so the identity path carries signal and gradient straight through. Transformers combine them as pre-norm blocks: x + f(Norm(x)).

2 · Limitation

What initialisation alone can't fix

Drift during training

Weights change, so the carefully balanced scales at step 0 do not stay balanced.

Products of Jacobians

Without a shortcut, gradients through 100 layers are a product of 100 factors.

Degradation

He et al. found deeper plain networks had higher training error than shallower ones: an optimisation failure, not overfitting.

4 · Core idea

Normalise inside, add outside

BatchNorm

Normalise each feature over the batch (Ioffe & Szegedy, 2015). Great for CNNs (convolutional networks); awkward for variable-length sequences.

LayerNorm

Normalise each token's vector over its features, then scale and shift (Ba et al., 2016).

RMSNorm

Divide by the root mean square only, no mean subtraction (Zhang & Sennrich, 2019): cheaper, same quality.

Residual

x + f(x): each block adds a correction to a running "residual stream" (He et al., 2016).

At a glance

The gradient of x + f(x) is I + f′(x): the identity term never vanishes.

5 · How it works

Inside one pre-norm transformer block

1 · stream x

Each token's vector of size d, carried through all layers.

2 · attention branch

x ← x + Attention(RMSNorm(x)).

3 · MLP branch

x ← x + MLP(RMSNorm(x)).

4 · final norm

After the last block, RMSNorm(x), then the output projection to logits.

5 · How it works

Worked example: what the identity path buys

A stack of L blocks. Plain: x ← f(x). Residual: x ← x + f(x). Backward multiplies by each block's Jacobian.

Worked example

  1. Plain stack: gradient = Πₗ f′ₗ. If each factor has size 0.9, after 100 layers the gradient is 0.9¹⁰⁰ ≈ 2.7 × 10⁻⁵.
  2. Residual stack: gradient = Πₗ (I + f′ₗ). Expanding the product, one term is the identity itself, so the bottom layer always gets the top gradient directly.
  3. ResNet trained networks of over 100 layers this way; BatchNorm reached the same accuracy with 14× fewer training steps.
  4. Pre-norm puts the norm inside the branch (x + f(Norm(x))) so the identity path stays clean; most modern LLMs (large language models) use pre-norm with RMSNorm.
Normalisation keeps each layer's inputs well scaled; residuals keep a clean path for signals and gradients through any depth.
6 · Why it works

Why the combination is so robust

Scale invariance

A normalised layer's output does not depend on the scale of its input, so drift upstream cannot blow it up.

Identity at init

With small branch outputs, a residual network starts close to the identity function: easy to optimise.

Higher learning rates

Normalisation allows much larger steps (BatchNorm's 14× fewer steps).

Residual stream view

Each layer reads from and writes to a shared stream, which is how interpretability work describes transformers.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Normalisation layers just speed up training a little."

For deep transformers they are often the difference between training and diverging.

"Residual connections add many parameters."

They add none: just an addition.

"LayerNorm and BatchNorm are the same thing."

BatchNorm averages over examples for each feature; LayerNorm over features for each example (token).
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Pre-norm: x + f(Norm(x)). Stable for deep stacks.
  • RMSNorm = LayerNorm without mean-centering. Cheaper, used by Llama.
  • LayerNorm normalises per token. Works with any batch size, unlike BatchNorm.

⚠ Traps

  • BatchNorm in sequence models. Statistics depend on the batch and padding.
  • Post-norm at large depth. Norm on the residual path can make training unstable without careful warmup.
  • Forgetting the final norm. Pre-norm stacks need one before the output head.

What does RMSNorm drop compared with LayerNorm?

Mean subtraction (and usually the bias).

Write a pre-norm transformer block.

x ← x + Attn(Norm(x)); x ← x + MLP(Norm(x)).

Why is BatchNorm rarely used in LLMs?

Its statistics depend on the batch, which varies with sequence length, padding and generation one token at a time; LayerNorm/RMSNorm work per token.
9 · Key takeaway

Key takeaway

Normalisation keeps each layer's inputs at a fixed scale and residual connections give an identity path, so pre-norm blocks x + f(Norm(x)) train at any depth.
Say it in 30 seconds

Good initialisation balances scales only at the start, and gradients in a deep plain stack are products of many factors. Normalisation layers rescale activations at every layer: BatchNorm over the batch for each feature, LayerNorm over each token's features, and RMSNorm the same without subtracting the mean. Residual connections add each layer's output to its input, so the gradient always includes an identity path and deep networks start near the identity. Modern LLMs use pre-norm blocks, x plus attention of norm x, then x plus MLP of norm x, usually with RMSNorm and a final norm before the output.

Problem: scale drift; vanishing gradient products.
Core idea: normalise inside the branch, add outside.
In LLMs: pre-norm RMSNorm blocks.

Further reading

Key papers

The primary sources behind this deck, each with what it contributed. Links go to the paper (arXiv or the conference page).

Deep Residual Learning for Image Recognition (ResNet)
He et al. · CVPR 2016

Residual connections make very deep networks trainable by letting each block learn a correction to the identity.

Remember: 152 layers; 3.57% ImageNet test error (ensemble)
Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift
Ioffe & Szegedy · ICML 2015

Normalizes each feature over the mini-batch, allowing much higher learning rates and less careful initialization.

Remember: same accuracy with 14× fewer training steps
Layer Normalization
Ba et al. · arXiv 2016

Normalizes over all features of one training case instead of over the mini-batch, so it works for any batch size and for recurrent nets.

Root Mean Square Layer Normalization
Zhang & Sennrich · NeurIPS 2019

Drops LayerNorm's mean-centring and keeps only re-scaling by the root mean square, with comparable quality.

Remember: 7–64% less running time
