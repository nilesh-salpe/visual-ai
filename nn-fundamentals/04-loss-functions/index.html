Loss functions

What a loss tells the optimizer: mean squared error for regression, cross-entropy for classification and next-token prediction, and label smoothing.

What is the problem?Training needs one number that is low when the model is right and whose gradient points toward being more right. A poor choice gives weak or misleading gradients.
Core ideaMSE (mean squared error) suits real-valued targets. For probabilities use cross-entropy −log p(correct): with a softmax its logit gradient is p − y, which stays large when the model is confidently wrong. Label smoothing mixes the one-hot target with a uniform distribution.
1 · Problem

How hard does each loss push?

The true label is 1. Move the model's predicted probability p. Compare the loss and, more importantly, the gradient with respect to the logit for cross-entropy and for MSE.

2 · Limitation

What a bad loss does

Weak gradients

MSE through a sigmoid or softmax barely moves confidently wrong predictions.

Wrong objective

Accuracy is what we care about but it is flat almost everywhere: no gradient.

Over-confidence

Cross-entropy with hard targets rewards pushing logits to infinity, hurting calibration and generalisation.

3 · Your turn

Which gradient is bigger?

Pick an answer before moving on. Committing to a guess, even a wrong one, makes the real answer stick.

True class probability is 0.01. Which loss gives the larger gradient on the logit?

B. Cross-entropy: |p − 1| = 0.99. MSE: |2(p − 1)p(1 − p)| ≈ 0.02, about 50× smaller.
4 · Core idea

Match the loss to the output

Mean squared error

L = mean (ŷ − y)². Real-valued targets; gradient 2(ŷ − y).

Cross-entropy

L = −Σ yᵢ log pᵢ. Probabilities; with softmax, ∂L/∂z = p − y.

Label smoothing

Replace the one-hot y with (1 − ε)·y + ε/K. Discourages infinite logits (Szegedy et al., 2016).

At a glance

The same loss trains classifiers and every LLM (large language model).

5 · How it works

Worked example: confidently wrong

Binary classifier with sigmoid output p = σ(z); true label 1 but the model outputs p = 0.01.

Worked example

  1. Cross-entropy: loss = −ln 0.01 = 4.61; gradient w.r.t. z = p − 1 = −0.99: a strong push.
  2. MSE on the probability: loss = (p − 1)² = 0.980; gradient w.r.t. z = 2(p − 1)·p(1 − p) = -0.0196: almost nothing.
  3. So with MSE the worst mistakes learn the slowest, because the sigmoid is saturated.
  4. Label smoothing ε = 0.1 over K classes: target 1 − ε + ε/K for the true class, ε/K elsewhere. Inception-v3 used ε = 0.1 with K = 1,000 and gained about 0.2% top-1 and top-5.
Cross-entropy undoes the softmax's saturation; that is why it is the default for anything that outputs probabilities.
6 · Why it works

Why cross-entropy is the default

Maximum likelihood

Minimising it maximises the probability of the data (Math deck 06).

Clean gradient

p − y: proportional to how wrong the prediction is, never saturating.

Proper scoring rule

The expected loss is minimised by reporting true probabilities.

Works per token

Each position gives an independent, cheap training signal.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"MSE and cross-entropy are interchangeable for classification."

They have the same minimum but very different gradients; MSE learns slowly from confident mistakes.

"Lower loss always means higher accuracy."

Usually correlated, but loss also rewards calibration; two models can swap order on the two metrics.

"Label smoothing is only for image models."

The original Transformer used ε = 0.1 too; it is optional for LLM pretraining and usually off.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Softmax + CE (cross-entropy) → gradient p − y. No saturation.
  • Regression → MSE (or Huber for outliers). Classification → cross-entropy.
  • Average over tokens. So the scale is independent of batch and sequence length.

⚠ Traps

  • MSE on probabilities. Vanishing gradients when confidently wrong.
  • Computing log(softmax). Use log-softmax / fused cross-entropy (Math deck 08).
  • Over-smoothing labels. Large ε hurts calibration-sensitive uses like distillation.
8 · Check yourself

Check yourself

Answer from memory. If you can't, revisit the slide named in the answer.

Gradient of softmax + cross-entropy with respect to the logits?

p − y.

Why does MSE on a sigmoid output learn slowly from confident mistakes?

Its gradient contains σ′ = p(1 − p), which is ≈ 0 when p is near 0 or 1.

Smoothed target for the true class with ε = 0.1 and K = 10?

1 − 0.1 + 0.1/10 = 0.91.
9 · Key takeaway

Key takeaway

Use MSE for real-valued targets and cross-entropy for probabilities: with softmax its gradient p − y never saturates, which is why it trains every LLM.
Say it in 30 seconds

A loss turns predictions into one number to minimise, and its gradient decides how the model changes. Mean squared error suits real-valued targets. For probabilities, cross-entropy, minus the log probability of the correct answer, is the right choice: combined with a softmax its gradient on the logits is just the predicted probabilities minus the target, so a confidently wrong prediction gets a strong correction. Squared error on probabilities would multiply in the sigmoid's tiny slope and barely learn. Label smoothing mixes a little uniform probability into the target to discourage over-confidence.

Problem: one number with a useful gradient.
Core idea: cross-entropy for probabilities, gradient p − y.
Extras: label smoothing; MSE for regression.
