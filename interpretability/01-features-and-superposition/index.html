Interpretability · 01

Features and superposition

What interpretability looks for inside a network: features as directions in activation space, why single neurons are polysemantic, and how sparse features are packed into fewer dimensions than there are features.

What is the problem?To understand or audit a model you want to know what its internal activations represent. Looking at individual neurons fails: a single neuron often responds to several unrelated concepts (polysemanticity), so "what does neuron 1,234 do?" has no clean answer.
Core ideaTreat a feature as a direction in activation space rather than a neuron. When features are sparse (rarely active at the same time), a network can store more features than it has dimensions by giving them nearly orthogonal directions: superposition. The cost is interference between features, which nonlinearities filter out. Superposition explains polysemantic neurons and motivates dictionary learning (deck 02).

2 · Limitation

Why neurons are the wrong unit

Basis is arbitrary

Nothing forces the network to align concepts with individual neurons; any rotation of a layer's space works as well for the next layer, except where nonlinearities act.

Dimensions are scarce

A layer with d dimensions has only d orthogonal directions.

PCA does not help

Principal components are dense directions of maximum variance, at most d of them.

4 · Core idea

Features as directions, packed in superposition

Feature = direction

A concept is represented by how far the activation vector points along a direction.

Superposition

With sparse features, the model stores more of them than it has dimensions, as nearly orthogonal directions, accepting interference.

Sparsity decides

Dense features: only the most important get dimensions. Sparse: more are packed, with phase changes between regimes and polytope geometry.

Circuits use features

Mechanisms like induction heads ([A][B] ... [A] → [B]) are built from such features; induction heads appear exactly when in-context learning improves sharply during training.

5 · How it works

Worked example: five features in two dimensions

The toy model from Toy Models of Superposition: five features of different importance, embedded in 2 dimensions, followed by a ReLU (rectified linear unit).

Worked example

  1. Dense features (often active together): the model represents the two most important features on orthogonal directions, like PCA (principal component analysis), and drops the other three.
  2. Sparse features (rarely active together): the model stores all five, as the vertices of a pentagon.
  3. Neighbouring pentagon directions are 72° apart: cosine 0.31, so an active feature leaks 0.31 onto its neighbours (interference).
  4. Because features are rarely active together, a ReLU with a small negative bias removes most of that leakage.
Sparsity is what makes superposition worth it: occasional interference costs less than dropping features.
6 · Why it works

Why networks do this

Capacity

The world has far more useful features than any layer has dimensions.

Sparsity is natural

Most concepts (a city, a programming language, DNA (deoxyribonucleic acid)) are absent from most inputs.

Nonlinear filtering

ReLU-like nonlinearities suppress small interference terms, making overlap cheap.

Consequences

Polysemantic neurons, a link to adversarial examples, and the need for dictionary learning to recover features.

7 · Misconceptions

Common misconceptions

Each statement below is a mental model people often get wrong. Decide why it is wrong, then reveal.

"Each neuron stands for one concept."

Superposition spreads features across neurons, so most neurons are polysemantic.

"A model can store at most d features in d dimensions."

Only if features are dense; sparse features can be packed far beyond d with tolerable interference.

"Interpretability means reading the weights."

Weights alone are hard to read; most methods study activations on real inputs and test causal effects.
7 · Tricks and traps

Tricks and traps

Rules of thumb that make this topic quick to reason about, and the mistakes people most often make with it.

✓ Tricks

  • Features are directions. Analyse projections onto directions, not single neuron values.
  • Sparsity enables superposition. Dense features get orthogonal dimensions; sparse ones share.
  • Phase changes. As sparsity grows, features switch abruptly from absent to stored in superposition.

⚠ Traps

  • Reading a neuron as a concept. Polysemantic neurons respond to several unrelated features.
  • Assuming orthogonality. With more features than dimensions, directions must overlap.
  • Equating PCA with features. PCA finds at most d dense directions, not the sparse features.

9 · Key takeaway

Key takeaway

Networks store more features than they have neurons by packing sparse features into overlapping directions.
Say it in 30 seconds

Interpretability treats features as directions in activation space. Individual neurons are often polysemantic because of superposition: when features are sparse, a network can represent more of them than it has dimensions by giving them nearly orthogonal directions and tolerating interference. In the toy model, five features in two dimensions are dropped down to two when dense, but stored as a pentagon when sparse. This is why later methods look for an overcomplete set of sparse directions instead of reading neurons.

Feature: a direction in activation space
Polysemantic: one neuron, many features
Superposition: more sparse features than dimensions
Cost: interference, filtered by nonlinearities

Further reading

Key papers

The primary sources behind this deck, each with what it contributed. Links go to the paper (arXiv or the conference page).

Toy Models of Superposition
Elhage et al. (Anthropic) · Transformer Circuits Thread 2022

Polysemanticity arises when models store more sparse features than dimensions in superposition; with dense features a toy model keeps only the most important (like PCA), with sparse features it packs more (e.g. five in two dimensions), with phase changes, polytope geometry and a link to adversarial examples.

In-context Learning and Induction Heads
Olsson et al. (Anthropic) · Transformer Circuits Thread 2022

Induction heads complete [A][B] ... [A] → [B]; they form at the same point as a sharp rise in in-context learning (a bump in the training loss); causal evidence in small attention-only models, correlational in larger ones.

Towards Monosemanticity: Decomposing Language Models With Dictionary Learning
Bricken et al. (Anthropic) · Transformer Circuits Thread 2023

Sparse autoencoders on the 512-neuron MLP (multilayer perceptron) of a one-layer transformer, trained on 8 billion activations, with 512 to 131,072 features (analysis on 4,096); features for Arabic script, DNA, base64 and Hebrew; a single neuron mixes academic citations, English dialogue, HTTP requests and Korean text.
