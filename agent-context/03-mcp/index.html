Model Context Protocol (MCP)

The open standard for connecting AI (artificial intelligence) applications to tools and data: hosts, clients and servers over JSON-RPC (JSON = JavaScript Object Notation) 2.0, the three server features, transports, and what changed in the stateless 2026-07-28 revision.

What is the problem?Every AI application integrated every data source and tool with custom code: N applications × M integrations, each with its own auth, schemas and quirks.
Core ideaMCP (Model Context Protocol) standardises the connection. Hosts (AI applications) run clients that talk to servers using JSON-RPC 2.0. Servers expose tools (model-controlled functions), resources (context data) and prompts (templates). In revision 2026-07-28 every request is self-contained: it carries its protocol version and capabilities, with no initialize handshake or session.

1 · Problem

N × M integrations

Custom connectors

Each app re-implements GitHub, Slack, databases, file systems…

Inconsistent semantics

Different schemas, errors and auth flows per integration.

No reuse

A connector written for one assistant does not work in another.

2 · Core idea

One protocol between apps and capabilities

Roles

Host: the LLM (large language model) application. Client: a connector inside the host. Server: a service providing context and capabilities.

Messages

JSON-RPC 2.0, UTF-8 (UTF = Unicode Transformation Format). Inspired by the Language Server Protocol for editors.

Server features

Tools (model-controlled functions), resources (data for the user or model), prompts (templated workflows).

Client features

Elicitation: servers can ask for more information from the user, through the client.

Anthropic introduced MCP on 25 November 2024 as "a universal, open standard for connecting AI systems with data sources". This deck follows specification revision 2026-07-28.

7 · Challenges in production

In production

Authorization

Remote servers use OAuth-based authorization; clients must validate the issuer (iss) and bind credentials to it.

Caching

Honour ttlMs/cacheScope on list results; deterministic tool order helps prompt caching.

Observability

Propagate OpenTelemetry trace context in _meta (traceparent, tracestate).

Migration

Dual-era implementations support both the stateless and legacy handshake-based revisions.

Model Context Protocol specification (revision 2026-07-28)
MCP maintainers · modelcontextprotocol.io 2026

Hosts, clients and servers over JSON-RPC 2.0; servers offer tools, resources and prompts; stdio and Streamable HTTP transports; stateless requests with per-request protocol version and capabilities.

MCP specification changelog (2026-07-28)
MCP maintainers · modelcontextprotocol.io 2026

Removes the initialize handshake and sessions, adds server/discover and subscriptions/listen, replaces server-initiated requests with multi round-trip requests (input_required).
