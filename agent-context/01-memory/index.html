Memory and context management

How agents remember: the context window as working memory, compaction and notes for long tasks, and long-term stores with scored retrieval and reflection.

What is the problem?The context window is finite and gets less reliable as it fills ("context rot"; models miss facts in the middle of long contexts), yet agents run for many steps and users expect them to remember across sessions.
Core ideaTreat context as a scarce attention budget. Keep working memory curated; compact (summarise and restart) near the limit; write structured notes to external storage; retrieve long-term memories by a score such as recency + importance + relevance (Generative Agents) or let the model page memory in and out itself (MemGPT).

1 · Problem

Context is finite and fragile

Context rot

As tokens increase, recall of information in the context decreases (Anthropic, context engineering).

Lost in the middle

Performance is often highest when relevant information is at the start or end and degrades in the middle (Liu et al.).

Sessions end

Nothing persists unless the agent writes it somewhere.

2 · Core idea

Tiers of memory

Working memory

The context window: system prompt, task, recent steps, retrieved items. Curate it.

Compaction

Near the limit, summarise the conversation and start a new context with the summary.

Structured notes

The agent writes progress, decisions and to-dos to files or a store and reads them back later.

Long-term memory

Episodes, facts and reflections retrieved on demand; MemGPT pages them in and out like OS (operating system) virtual memory.

4 · Low-level design

Scoring and writing memories

Write policy

What to store: decisions, user preferences, outcomes; not every token.

Compaction trigger

At a set fraction of the window, summarise and restart; keep the goal and open issues verbatim.

Forget policy

Expire, deduplicate and correct memories; contradictions must be resolved.

5 · Trade-offs

Trade-offs

Choice Benefit Cost
Keep full history in context nothing lost context rot, cost grows every step
Compaction (summarise) long tasks fit details can be lost in the summary
Retrieval from a store scales to large memories retrieval misses; embedding and storage cost
Agent-managed memory (MemGPT-style) model decides what to keep extra tool calls; model may manage it badly
Just-in-time loading only identifiers in context, data fetched when needed more tool calls, latency
6 · Failure modes

Failure modes

Failure Symptom Mitigation
Stale or contradictory memories acts on outdated preferences timestamps, update-in-place, conflict resolution
Lossy compaction forgets a constraint after summarising pin critical facts; test summaries
Memory poisoning injected text persists and steers future sessions validate what gets written; provenance
Cross-user leakage one user's data appears for another strict per-user/tenant isolation
Needle missed fact in context but ignored put key facts at the start or end; retrieve fewer, better items
7 · Challenges in production

In production

Privacy and deletion

Users must be able to see and delete memories; retention policies apply.

Multi-tenancy

Memory stores keyed and access-controlled per user and organisation.

Evaluate recall

Test that the right memory is retrieved and used, not just stored.

Cost

Embeddings, storage and longer prompts all cost money at scale.

Effective context engineering for AI (artificial intelligence) agents
Anthropic · Anthropic Engineering 2025

Context as a finite "attention budget" (context rot); just-in-time retrieval; compaction, structured note-taking and sub-agents for long-horizon tasks.

MemGPT: Towards LLMs (large language models) as Operating Systems
Packer et al. · arXiv 2023

Virtual context management: the LLM moves information between a limited main context and external memory tiers via function calls, like OS paging.

Generative Agents: Interactive Simulacra of Human Behavior
Park et al. · UIST 2023

A memory stream of observations retrieved by recency, importance and relevance, periodically synthesised into reflections that guide planning.

Remember: retrieval score = recency + importance + relevance (each min-max scaled, weights 1)
Lost in the Middle: How Language Models Use Long Contexts
Liu et al. · TACL 2024

Performance is often highest when relevant information is at the beginning or end of the context and degrades when it is in the middle.
