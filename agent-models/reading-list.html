Models for agents: key papers

Every paper cited on the decks' Key papers slides, in the order the guide introduces them. Each entry links to the paper and to the decks that use it.

Toolformer: Language Models Can Teach Themselves to Use Tools
Schick et al. · NeurIPS 2023 · cited in Training LLMs for agents

A model trained self-supervised to decide which APIs to call, when, and with what arguments (calculator, search, QA, translation, calendar).

Gorilla: Large Language Model Connected with Massive APIs
Patil et al. · NeurIPS 2024 · cited in Training LLMs for agents

A LLaMA model fine-tuned to write API calls, trained with retrieved API documentation so it adapts to documentation changes at test time; APIBench evaluation.

ToolLLM: Facilitating Large Language Models to Master 16000+ Real-world APIs
Qin et al. · ICLR 2024 · cited in Training LLMs for agents

ToolBench: 16,464 real REST APIs in 49 categories, instructions and solution paths generated by ChatGPT with a depth-first decision-tree search; ToolLLaMA generalises to unseen APIs.

Kimi K2: Open Agentic Intelligence
Kimi Team · arXiv 2025 · cited in Training LLMs for agents

Agentic post-training: a synthesis pipeline (tool specs → agents and rubric-graded tasks → multi-turn trajectories filtered by a judge, plus real sandboxes for code) and joint RL with verifiable rewards and a self-critique rubric reward.

Remember: 3,000+ real MCP tools and 20,000+ synthetic tools; 65.8 on SWE-bench Verified, 66.1 on Tau2-Bench
SWE-RL: Advancing LLM Reasoning via Reinforcement Learning on Open Software Evolution
Wei et al. · arXiv 2025 · cited in Training LLMs for agents

RL on software-evolution data (issues, pull requests, code changes) with a rule-based reward (similarity to the real patch); RL improved out-of-domain skills where an SFT baseline degraded them.

Remember: Llama3-SWE-RL-70B solves 41.0% of SWE-bench Verified
DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning
DeepSeek-AI · arXiv 2025 · cited in Training LLMs for agents

R1-Zero: RL with rule-based accuracy and format rewards directly on a base model; R1 adds cold-start data and a multi-stage pipeline.

Remember: AIME (American Invitational Mathematics Examination) 2024 pass@1 15.6% → 77.9% (R1-Zero)
SGLang: Efficient Execution of Structured Language Model Programs
Zheng et al. · NeurIPS 2024 · cited in Serving LLMs for agent workloads

A runtime and frontend for multi-call LLM (large language model) programs; RadixAttention keeps KV caches in a radix tree so shared prefixes are reused across requests automatically.

Remember: up to 6.4× higher throughput
XGrammar: Flexible and Efficient Structured Generation Engine for Large Language Models
Dong et al. · MLSys 2025 · cited in Serving LLMs for agent workloads

Constrained decoding with context-free grammars: context-independent tokens are prechecked into masks, only context-dependent tokens are checked at runtime with a persistent stack, and mask computation overlaps GPU work.

Remember: up to 100× faster grammar execution; near-zero overhead end to end
Efficient Guided Generation for Large Language Models
Willard & Louf · arXiv 2023 · cited in Serving LLMs for agent workloads

Guided generation as finite-state-machine transitions with an index over the vocabulary, enforcing regular expressions and grammars (the Outlines library).

Let Me Speak Freely? A Study on the Impact of Format Restrictions on Performance of Large Language Models
Tam et al. · EMNLP Industry 2024 · cited in Serving LLMs for agent workloads

Format restrictions such as forced JSON can significantly reduce reasoning performance, and stricter constraints degrade it more.

Autellix: An Efficient Serving Engine for LLM Agents as General Programs
Luo et al. · arXiv 2025 · cited in Serving LLMs for agent workloads

Treats agent programs as first-class units; schedulers preempt and prioritise calls using each program's completed calls to avoid head-of-line blocking.

Remember: 4-15× higher program throughput at the same latency vs vLLM
Parrot: Efficient Serving of LLM-based Applications with Semantic Variable
Lin et al. · OSDI 2024 · cited in Serving LLMs for agent workloads

Semantic Variables expose the data flow between an application's LLM requests so the service can schedule and share prefixes across them.

Remember: up to an order-of-magnitude end-to-end improvement
Automatic Prefix Caching (design)
vLLM documentation · docs.vllm.ai 2026 · cited in Serving LLMs for agent workloads

Each KV block is hashed with its tokens and the prefix before it; blocks are reference-counted, freed blocks are evicted in LRU (least recently used) order, and cache hits skip prefill.
