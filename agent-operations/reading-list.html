Agent operations: key papers

Every paper cited on the decks' Key papers slides, in the order the guide introduces them. Each entry links to the paper and to the decks that use it.

τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains
Yao et al. · arXiv 2024 · cited in Evaluating agents

Simulated users, domain APIs and policies; grades the final database state and introduces pass^k to measure consistency across trials.

Remember: gpt-4o < 50% success; pass^8 < 25% in retail
SWE-bench: Can Language Models Resolve Real-World GitHub Issues?
Jimenez et al. · ICLR 2024 · cited in Evaluating agents

Real GitHub issues: the model edits the repository and the project's own tests decide success.

Remember: 2,294 issues; Claude 2 solved 1.96% at release
GAIA: a benchmark for General AI (artificial intelligence) Assistants
Mialon et al. · ICLR 2024 · cited in Evaluating agents

466 real-world questions that are simple for humans but need reasoning, browsing, multimodality and tool use.

Remember: humans 92% vs 15% for GPT-4 with plugins
OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments
Xie et al. · NeurIPS 2024 · cited in Evaluating agents

369 real desktop and web tasks across operating systems with execution-based evaluation scripts.

Remember: humans 72.36% vs best model 12.24% (at release)
AgentBench: Evaluating LLMs as Agents
Liu et al. · ICLR 2024 · cited in Evaluating agents

Eight interactive environments for LLM agents; poor long-term reasoning, decision-making and instruction following are the main failure causes.

Not what you've signed up for: Compromising Real-World LLM-Integrated (LLM = large language model) Applications with Indirect Prompt Injection
Greshake et al. · AISec 2023 · cited in Safety and reliability

Instructions planted in data the application retrieves (web pages, emails, documents) can hijack LLM-integrated apps: data theft, worming, manipulation.

AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents
Debenedetti et al. · NeurIPS Datasets and Benchmarks 2024 · cited in Safety and reliability

An extensible environment of realistic agent tasks with injected tool outputs to measure attacks and defenses.

Remember: 97 tasks, 629 security test cases
Computer use tool
Anthropic documentation · platform.claude.com 2026 · cited in Safety and reliability

Screenshot, mouse and keyboard control in an agent loop; recommends a dedicated VM or container, no sensitive data, a domain allowlist and human confirmation for consequential actions.

Model Context Protocol specification (revision 2026-07-28)
MCP maintainers · modelcontextprotocol.io 2026 · cited in Safety and reliability

Hosts, clients and servers over JSON-RPC (JSON = JavaScript Object Notation) 2.0; servers offer tools, resources and prompts; stdio and Streamable HTTP (Hypertext Transfer Protocol) transports; stateless requests with per-request protocol version and capabilities.

Prompt caching
Anthropic documentation · platform.claude.com 2026 · cited in Cost and latency

Reuse of cached prompt prefixes: 5-minute cache writes cost 1.25× base input, 1-hour writes 2×, and reads 0.1× on most models (lower on some newer ones).

How we built our multi-agent research system
Anthropic · Anthropic Engineering 2025 · cited in Cost and latency

A lead agent plans and spawns parallel subagents with separate context windows; lessons on delegation, effort scaling, tools, evaluation and production reliability.

Remember: +90.2% vs single agent on an internal research eval; ~15× chat tokens
Building effective agents
Anthropic · Anthropic Engineering 2024 · cited in Cost and latency

Workflows (predefined code paths) vs agents (LLMs (large language models) directing their own process); patterns: prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer. Start with the simplest solution.
